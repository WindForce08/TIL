행렬과 가우스 소거법

“행렬을 왜 배우는가?”에서 시작해 기저벡터, 행렬 표현, 행 연산, 사다리꼴, 피벗, 가우스 소거법까지
학습지도행렬의 정체표현의 약속 벡터·기저행렬 연산행렬 종류 가우스 소거피벗왜 사다리꼴? 활용복습

0. 이번 학습의 핵심 지도

가장 먼저 기억할 문장
행렬은 단순한 숫자표가 아니라, 여러 입력과 출력 사이의 관계를 체계적으로 기록하는 표현이며, 특히 벡터를 다른 벡터로 바꾸는 선형적인 규칙을 표현하는 데 강력하다.
1단계
연립방정식 → 계수들을 정리한다.
2단계
벡터 → 여러 값을 하나의 묶음으로 본다.
3단계
행렬 → 입력과 출력의 관계/변환을 기록한다.
4단계
행렬 연산 → 관계나 변환을 합성·결합한다.
5단계
가우스 소거 → 연립방정식의 변수를 하나씩 없앤다.
6단계
피벗 → 각 소거 단계의 기준점이다.

추천 학습 순서: 행렬의 의미 → 행/열의 약속 → 벡터·기저 → 행렬곱 → 행렬 종류 → 연립방정식 → 행 연산 → 사다리꼴 → 피벗 → 가우스 소거 → Physical AI 활용

1. 행렬은 대체 무엇인가?

처음부터 “행렬은 숫자를 직사각형으로 배열한 것”이라고 외우면 왜?가 남습니다.

핵심 관점: 행렬을 하나의 변환 장치 또는 관계 기록표로 생각한다.

예: 두 입력을 두 출력으로 바꾸는 규칙

y₁ = 2x + y
y₂ = 3y

이 관계를 행렬로 기록하면

A = [ 2 1
    0 3 ]

이고,

A [x, y]ᵀ = [2x+y, 3y]ᵀ

입니다. 첫 번째 행 [2 1]은 첫 번째 출력의 계수, 두 번째 행 [0 3]은 두 번째 출력의 계수입니다.

행렬의 각 값은 무엇을 뜻하는가?

상황행렬 원소의 의미 예
연립방정식변수들의 계수
선형변환입력 성분이 출력 성분에 미치는 계수
이미지픽셀의 밝기/색상 같은 데이터
머신러닝입력 특징을 출력 특징으로 조합하는 가중치
로봇/물리좌표·자세·상태를 변환하는 관계의 계수
중요: 같은 숫자 배열이라도 문맥에 따라 의미가 달라진다. 행렬 자체가 항상 “회전”이나 “데이터”인 것은 아니다.

2. “무슨 약속으로 모든 걸 행렬로 바꾸는가?”

아무렇게나 바꾸는 것이 아닙니다. 먼저 무엇을 입력으로 보고 무엇을 출력으로 볼지, 변수의 순서를 정합니다.

연립방정식의 경우

x + y = 5
2x + y = 7

변수 순서를 x → y로 정하면 계수와 결과를 다음처럼 배치합니다.

       x   y | 결과
       ↓   ↓ | ↓
[      1   1 |  5 ]
[      2   1 |  7 ]

즉 첫 번째 열은 x의 계수, 두 번째 열은 y의 계수, 마지막 열은 우변입니다.

왜 행과 열의 위치가 중요할까?

행렬은 위치 자체가 의미를 가집니다. 약속한 변수 순서를 바꾸면 열의 의미도 함께 바뀝니다.

따라서 “행렬을 만드는 기준”은 문제에서 정한 입력/출력의 순서와 관계입니다.

첨가행렬(augmented matrix)

연립방정식의 계수 행렬과 우변을 한 번에 적은 형태입니다.

[ A | b ]

예: [1 1 | 5; 2 1 | 7]. 가운데 세로선은 계산 대상의 구분을 눈으로 보여주는 표기입니다.

3. 벡터와 기저벡터

벡터

벡터는 여러 값을 하나의 묶음으로 보는 대상입니다. 예를 들어

v = [3, 2]ᵀ

는 2차원에서 “x 방향 3, y 방향 2”라는 정보를 담을 수 있습니다.

기저벡터

기저벡터는 공간의 벡터를 표현하기 위한 기본 방향입니다.

e₁ = [1,0]ᵀ,    e₂ = [0,1]ᵀ

그러면

[3,2]ᵀ = 3e₁ + 2e₂

가 됩니다.

현재 단계에서의 정의: 기저 = “공간의 모든 위치/벡터를 조합해서 표현할 수 있게 해주는 기본 방향들의 집합”.

가우스 소거를 시작할 때 기저를 깊게 이해할 필요는 없지만, 이후 선형변환을 이해하면 행렬과 자연스럽게 연결됩니다.

4. 왜 행렬을 더하고 곱할 수 있는가?

행렬 덧셈

두 변환의 효과를 더하고 싶다면

A x + B x = (A+B)x

가 됩니다. 그래서 행렬 덧셈은 “두 선형적인 효과를 합치는 것”으로 해석할 수 있습니다.

행렬 곱셈

핵심은 변환을 연속해서 적용하기 위해서입니다.

x → A x → B(Ax)

이 전체 과정을 하나의 행렬로 묶으면

B(Ax) = (BA)x

가 됩니다.

따라서 AB와 BA의 순서가 일반적으로 다릅니다. “A를 먼저 하고 B를 하는 것”과 “B를 먼저 하고 A를 하는 것”은 현실의 연속 작업에서도 보통 다르기 때문입니다.

행렬곱의 행·열 계산

행렬곱의 각 원소는 한 행과 한 열의 내적으로 만들어집니다.

(AB)ᵢⱼ = Σₖ aᵢₖ bₖⱼ

이 규칙은 임의의 장난이 아니라 “첫 번째 변환을 거친 결과를 두 번째 변환에 넣었을 때 생기는 식”을 정리한 것입니다.

5. 정사각행렬·대각행렬 등은 왜 따로 부르는가?

종류형태/조건직관
정사각행렬행 수 = 열 수같은 차원에서 같은 차원으로 가는 변환을 표현하기 좋음
대각행렬대각선 외 원소가 0각 축/성분을 서로 섞지 않고 독립적으로 스케일링
영행렬모든 원소가 0모든 것을 0으로 보냄
단위행렬 I대각선이 1, 나머지 0아무것도 바꾸지 않는 변환

대각행렬의 예

D[x,y,z]ᵀ = [2x, 5y, 10z]ᵀ

즉 x는 2배, y는 5배, z는 10배가 됩니다. 서로 섞이지 않습니다.

정사각행렬의 직관

2×2 행렬은 2개의 입력을 받아 2개의 출력으로 보내고, 3×3 행렬은 3개의 입력을 받아 3개의 출력으로 보내는 형태입니다. 로봇의 3차원 회전행렬이 대표적인 예입니다.

6. 가우스 소거법: 지금 배우는 핵심

한 문장: 가우스 소거법은 연립방정식의 변수를 하나씩 없애서 풀기 쉬운 계단식 구조를 만드는 방법입니다.

예제

x + y = 5
2x + y = 7

첨가행렬로 적으면

[ 1 1 | 5 ]
[ 2 1 | 7 ]

첫 번째 변수 x를 소거

두 번째 행에서 첫 번째 행의 2배를 뺍니다.

R₂ ← R₂ − 2R₁

계산하면

[ 1 1 | 5 ]
[ 0 −1 | −3 ]

이는 방정식으로

x + y = 5
−y = −3

이므로 y=3, x=2입니다.

3변수에서는

[ x y z ]
[ x y z ]
[ x y z ]

        ↓ x 소거

[ x y z ]
[ 0 y z ]
[ 0 y z ]

        ↓ y 소거

[ x y z ]
[ 0 y z ]
[ 0 0 z ]

이것이 가우스 소거의 핵심 패턴입니다.

7. 왜 행을 바꿔도 되는가? — 허용되는 3가지 행 연산

연산표기의미
행 교환Rᵢ ↔ Rⱼ방정식의 순서만 바꿈
행에 0이 아닌 상수 곱Rᵢ → cRᵢ방정식의 양변에 같은 수를 곱함
다른 행의 배수를 더함Rᵢ → Rᵢ + cRⱼ두 방정식을 조합해 새로운 동치 방정식을 만듦
주의: “행렬이니까 아무렇게나 더하고 곱해도 된다”가 아닙니다. 가우스 소거에서는 원래 연립방정식과 해집합을 유지하는 특정 행 연산만 사용하는 것입니다.

8. 왜 꼭 사다리꼴이어야 하는가?

사다리꼴 자체가 목적은 아닙니다.

변수를 하나씩 제거하면 자연스럽게 사다리 모양이 되고, 그 모양에서는 아래에서 위로 해를 쉽게 구할 수 있습니다.

예를 들어

x + y + z = 6
    y + z = 4
        z = 1

이면 마지막 식에서 z를 구하고 → 두 번째 식에서 y를 구하고 → 첫 번째 식에서 x를 구합니다.

[ x y z ]
[ 0 y z ]
[ 0 0 z ]
   ↓
 z 먼저
   ↓
 y
   ↓
 x

즉

x,y,z → y,z → z → 뒤에서부터 x,y,z를 복원

이 흐름이 핵심입니다.

9. 피벗(Pivot)이란?

피벗 = 현재 소거 단계에서 기준으로 사용하는 핵심 원소

예를 들어

[ 2 3 ]
[ 4 5 ]

에서 2를 기준으로 아래의 4를 0으로 만들면

R₂ ← R₂ − 2R₁

이고, 2가 첫 번째 피벗입니다.

사다리꼴

[ 1 2 3 ]
[ 0 4 5 ]
[ 0 0 7 ]

에서는 보통 1, 4, 7이 피벗입니다.

피벗의 위치가 중요한 이유

[ ●  *  * ]
[ 0  ●  * ]
[ 0  0  ● ]

피벗이 오른쪽 아래로 이동하면서 x → y → z 순으로 변수를 처리할 수 있습니다.

피벗이 꼭 1인가?

아닙니다. 2, 4, 7 같은 값도 피벗이 될 수 있습니다. 계산을 편하게 하려고 피벗을 1로 만드는 경우가 많을 뿐입니다.

피벗이 0이면?

그 위치에서는 소거 기준으로 쓸 수 없으므로 아래 행과 교환하여 0이 아닌 원소를 가져올 수 있습니다. 이것도 행 교환이 필요한 이유 중 하나입니다.

10. 가우스 소거법 전체 예제

다음 연립방정식을 봅니다.

x + y + z = 6
2x + y + z = 8
x + 2y + z = 9

첨가행렬:

[ 1 1 1 | 6 ]
[ 2 1 1 | 8 ]
[ 1 2 1 | 9 ]

① x 소거

R₂ ← R₂ − 2R₁
R₃ ← R₃ − R₁
[ 1 1 1 | 6 ]
[ 0 −1 −1 | −4 ]
[ 0 1 0 | 3 ]

② y 소거

R₂ ← R₂ + R₃
[ 1 1 1 | 6 ]
[ 0 0 −1 | −1 ]
[ 0 1 0 | 3 ]

행 순서를 바꾸어 깔끔하게 쓰면

[ 1 1 1 | 6 ]
[ 0 1 0 | 3 ]
[ 0 0 −1 | −1 ]

③ 뒤에서부터 풀이

−z = −1 → z=1
y = 3
x+y+z=6 → x=2
정답: x=2, y=3, z=1

11. 수학·물리·컴퓨터공학에서 왜 배우는가?

수학

연립방정식, 선형변환, 기저, 선형독립, 역행렬, 고유값 등을 하나의 언어로 다룬다.

물리

좌표변환, 회전, 힘·상태의 표현, 선형 시스템 등을 표현한다.

컴퓨터공학

이미지·데이터 배열, 그래픽스 변환, 머신러닝 가중치, 최적화 등에 사용된다.

Physical AI / 로봇

센서 좌표 → 로봇 좌표 → 세계 좌표 변환, SLAM, 자세 표현, 로봇팔, 제어 등에 사용된다.

로봇 좌표변환의 느낌

p_world = T_world^robot · T_robot^sensor · p_sensor

센서가 측정한 점을 로봇 좌표계와 세계 좌표계로 차례차례 변환하는 과정을 행렬로 표현할 수 있습니다.

제어에서는

xₜ₊₁ = A xₜ + B uₜ

현재 상태와 제어 입력으로 다음 상태를 계산하는 선형 시스템을 나타낼 수 있습니다.

스스로 설명해보기

Q1. 왜 [1 1 | 5]는 x+y=5인가?

변수 순서를 x, y로 약속했기 때문에 첫 번째 1은 x의 계수, 두 번째 1은 y의 계수, 5는 우변이다.

Q2. 왜 R₂ ← R₂ − 2R₁을 하는가?

두 번째 식의 x 계수가 2이므로 첫 번째 식의 2배를 빼면 x가 0이 되어 소거된다.

Q3. 왜 사다리꼴을 만드는가?

변수가 x,y,z → y,z → z 순으로 줄어들어 마지막 변수부터 거꾸로 쉽게 풀 수 있기 때문이다.

Q4. 피벗은 무엇인가?

현재 소거 단계에서 다른 원소를 0으로 만들기 위해 기준으로 사용하는 핵심 원소이다.

14. 현재 학습에서 아직 깊게 들어가지 않아도 되는 것

기저, 선형독립, 역행렬, 행렬식, 고유값, 고유벡터, 대각화 등은 중요하지만 지금 당장 모두 이해해야 가우스 소거를 할 수 있는 것은 아닙니다.

현재 우선순위:
① 행렬의 의미 → ② 행/열의 약속 → ③ 연립방정식의 행렬 표현 → ④ 행 연산 → ⑤ 변수 소거 → ⑥ 사다리꼴 → ⑦ 피벗 → ⑧ 가우스 소거 완주

학습 메모: “사다리꼴을 만들기 위해 변수를 없애는 것이 아니라, 변수를 하나씩 없애다 보니 사다리꼴이 된다.”

이번 대화에서 형성된 개념 흐름을 학습용으로 재구성한 문서입니다.
