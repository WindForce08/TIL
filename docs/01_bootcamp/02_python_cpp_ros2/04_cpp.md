## 1. 함수의 기본 구조

C++에서 `main()`도 하나의 함수이며, `main()` 외에도 여러 함수를 추가로 만들 수 있다.

```cpp
int sub();

int main()
{
    sub();

    return 0;
}

int sub()
{
    // 실행할 내용
    return 0;
}
```

- `main()`은 프로그램이 시작되는 특별한 함수
- `sub()` 같은 함수는 사용자가 추가로 정의할 수 있음
- `sub();`처럼 호출하면 해당 함수가 실행됨
- 함수가 `main()`보다 아래에 정의되어 있다면 `int sub();`처럼 먼저 선언해둘 수 있음
- 이를 함수 선언(프로토타입)이라고 함

---

## 2. 함수 내부에서 선언한 변수

각 함수에서 선언한 일반적인 변수는 기본적으로 해당 함수 내부에서만 사용할 수 있다.

```cpp
void sub()
{
    int a = 10;
}

int main()
{
    int b = 20;
}
```

- `a`는 `sub()`의 지역 변수
- `b`는 `main()`의 지역 변수
- `main()`에서는 `a`를 직접 사용할 수 없음
- `sub()`에서도 `b`를 직접 사용할 수 없음

즉:

> 함수 안에서 선언한 변수는 기본적으로 그 함수의 지역 변수이며, 다른 함수와 자동으로 공유되지 않는다.

함수끼리 데이터를 주고받으려면 이후에 배우는 **매개변수(parameter)**와 **반환값(return value)** 등을 사용한다.

---

## 3. 함수의 반환형

함수 이름 앞에 있는 `int`, `void` 등은 **반환형(return type)**이다.

### `int` 함수

```cpp
int getNumber()
{
    return 10;
}
```

- 이 함수는 정수 값을 반환함
- `return 10;`을 통해 호출한 곳에 `10`을 전달할 수 있음

```cpp
int result = getNumber();
```

실행 흐름:

```text
getNumber()
    ↓
10 반환
    ↓
result에 저장
```

### `void` 함수

```cpp
void hello()
{
    std::cout << "Hello";
}
```

- 이 함수는 반환값이 없음
- 실행 자체는 가능함
- `cout`으로 화면에 출력할 수 있음

---

## 4. 출력과 반환은 다르다

`cout`으로 화면에 보여주는 것과 `return`으로 값을 전달하는 것은 완전히 다른 개념이다.

### 출력

```cpp
void test()
{
    std::cout << "10";
}
```

화면에 `10`을 보여준다.

하지만 다른 코드에 `10`이라는 값을 전달한 것은 아니다.

### 반환

```cpp
int test()
{
    return 10;
}
```

화면에는 아무것도 출력하지 않는다.

대신:

```cpp
int result = test();
```

처럼 사용하면 `10`을 `result`에 전달할 수 있다.

정리:

```text
cout << 10
→ 사용자 화면에 10 출력

return 10
→ 호출한 코드에 10 전달
```

비유하면:

- `cout` = 화면에 보여주기
- `return` = 다른 코드에게 값 전달하기

## 5. `return`의 기본적인 역할

`return`은 **현재 실행 중인 함수를 즉시 종료하고 호출한 곳으로 돌아가는 것**이다.

예:

```cpp
int sub()
{
    std::cout << "A";

    return 0;

    std::cout << "B";
}
```

`return 0;` 이후의 `B` 출력 코드는 실행되지 않는다.

실행 흐름:

```text
sub()
 ↓
A 출력
 ↓
return 0
 ↓
sub() 종료
 ↓
호출했던 곳으로 돌아감
```

따라서 `return`은 단순히 값을 전달하는 명령이 아니라, **현재 함수를 종료시키는 역할도 한다.**

---

## 6. `main()`의 `return 0`

```cpp
int main()
{
    return 0;
}
```

여기서 `return 0;`은 화면에 `0`을 출력하는 것이 아니다.

`main()`이 반환형 `int`인 함수이므로 정수값을 반환하는 것이며, `0`은 일반적으로 **프로그램이 정상적으로 종료되었다는 상태 코드**로 사용된다.

```text
main()
 ↓
return 0
 ↓
main 종료
 ↓
프로그램 종료
```

또한 일반적인 C++에서는 `main()`의 끝까지 도달하면 `return 0;`을 생략해도 정상 종료로 처리된다.

예:

```cpp
int main()
{
    std::cout << "Hello";
}
```

도 정상적으로 동작한다.

## 7. 일반 함수의 `return 0`과 `main()`의 `return 0`

`return 0;`이라는 문법 자체의 의미는 동일하지만, **어떤 함수에서 실행하느냐에 따라 결과가 다르다.**

### 일반 함수

```cpp
int sub()
{
    return 0;
}
```

의미:

```text
sub()
 ↓
return 0
 ↓
sub() 종료
 ↓
호출했던 곳으로 복귀
```

예를 들어 `main()`에서 호출했다면 다시 `main()`으로 돌아온다.

### `main()` 함수

```cpp
int main()
{
    return 0;
}
```

의미:

```text
main()
 ↓
return 0
 ↓
main 종료
 ↓
프로그램 종료
```

정리:

| 위치 | `return 0;`의 효과 |
|---|---|
| 일반 함수 | 해당 함수 종료 → 호출한 곳으로 복귀 |
| `main()` | `main()` 종료 → 프로그램 종료 |

핵심:

> `return`은 항상 현재 실행 중인 함수를 종료한다.
>
> `main()`은 프로그램의 시작 함수이므로 `main()`에서 `return`하면 프로그램 전체가 종료된다.

## 8. 현재까지의 핵심 개념

### 함수

```cpp
int sub()
{
    // 함수 내용
}
```

함수는 특정 작업을 하나의 단위로 묶어놓은 것이다.

### 함수 호출

```cpp
sub();
```

함수를 실제로 실행한다.

### 함수 반환형

```cpp
int sub()
```

`int` → 정수를 반환할 수 있는 함수

```cpp
void sub()
```

`void` → 반환값이 없는 함수

### `return`

```cpp
return 10;
```

값을 반환하면서 현재 함수를 종료한다.

```cpp
return 0;
```

`0`을 반환하면서 현재 함수를 종료한다.

### `cout`

```cpp
std::cout << 10;
```

화면에 `10`을 출력한다.

---

## 9. 한 문장으로 정리

> **함수는 작업을 묶어놓은 단위이고, 함수 내부의 지역 변수는 기본적으로 그 함수에서만 사용할 수 있으며, `cout`은 값을 화면에 출력하고 `return`은 값을 호출한 곳에 전달하면서 현재 함수를 종료한다. `main()`에서 `return`하면 프로그램 전체가 종료된다.**
