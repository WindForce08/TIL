# 선형대수 구현 힌트지

가우스 소거법 · Rank · Determinant · 역행렬

> 목표: 아래 설명만 보고 직접 함수를 구현하세요. 완성된 코드는 제공하지 않습니다.
> NumPy의 `np.linalg`에 의존하지 않고, 배운 행 연산을 코드로 옮겨보세요.

## 1. 먼저 기억해야 할 것

이번 구현에서 가장 중요한 것은 **행 연산**입니다.
행렬 $A$에 다음 세 가지 연산을 적용할 수 있습니다.

1. 두 행을 교환: $R_i \leftrightarrow R_j$
2. 한 행에 상수를 곱하기: $R_i \leftarrow cR_i$
3. 한 행에 다른 행의 배수를 더하기: $R_i \leftarrow R_i + cR_j$

특히 가우스 소거에서는 ③번 연산을 가장 많이 사용합니다.

## 2. 구현의 핵심 구조

가우스 소거는 다음 순서로 생각하세요.

```
현재 열에서 피벗 찾기
        ↓
필요하면 행 교환
        ↓
피벗 아래의 값을 0으로 만들기
        ↓
다음 행으로 이동
        ↓
다음 열에서 반복
```

예를 들어

```
[ 2  4  1 ]
[ 6  7  3 ]
[ 4  8  5 ]
```

에서 첫 번째 피벗을 2라고 하면,

```
[ 2  4  1 ]
[ 0  ?  ? ]
[ 0  ?  ? ]
```

를 만드는 것이 첫 번째 목표입니다.

## 3. 힌트 ① — Row Echelon Form

```python
def row_echelon(A, pivoting=True):
    ...
```

입력 행렬을 복사한 뒤 행 사다리꼴로 변환하세요.

```
[ *  *  * ]
[ 0  *  * ]
[ 0  0  * ]
```

**Step 1. 행렬 복사**

원본 `A`를 직접 수정하지 않는 것이 좋습니다.

힌트: `np.array(..., dtype=float, copy=True)`

**Step 2. 행과 열의 크기 확인**

`m` = 행의 개수, `n` = 열의 개수

**Step 3. 현재 피벗 행을 기억**

처음에는 첫 번째 행입니다 (`row = 0`).
피벗을 하나 찾을 때마다 다음 행으로 이동합니다 (`row += 1`).

**Step 4. 열을 왼쪽부터 하나씩 확인**

`col = 0, 1, 2, ...` 순서로 진행하면서, 현재 열에서 피벗을 찾으세요.

**Step 5. 피벗 선택**

두 가지 방법을 지원합니다.

- `pivoting=True`: 현재 열에서 **절댓값이 가장 큰 값**을 선택합니다.

  ```
  [ 0.2 ]
  [ 5.7 ]  ← 피벗 후보
  [ 1.3 ]
  ```

  힌트: `np.argmax(...)`, `np.abs(...)`

- `pivoting=False`: 현재 행의 현재 열 값을 그대로 피벗으로 사용합니다.

**Step 6. 피벗이 0에 가까운 경우**

피벗이 사실상 0이라면 이 열에서는 피벗을 만들 수 없습니다.
그 경우 현재 열은 포기하고 다음 열로 이동합니다.

**Step 7. 필요한 경우 행 교환**

피벗 후보가 현재 행이 아니라면 $R_{current} \leftrightarrow R_{candidate}$ 를 수행하고,
행 교환 횟수를 하나 증가시킵니다 (`n_swaps += 1`).

왜 기록할까요? 나중에 행렬식의 부호를 계산할 때 사용합니다.

**Step 8. 피벗 아래를 0으로 만들기**

현재 피벗이 `A[row, col]`이고 아래쪽 원소가 `A[r, col]`이라면 소거 계수는

$$factor = \frac{A_{r,\,col}}{A_{row,\,col}}$$

이고, 행 연산

$$R_r \leftarrow R_r - factor \cdot R_{row}$$

를 수행합니다.

**Step 9. 피벗 기록**

피벗이 위치한 열 번호를 저장합니다. 예: `pivot_cols = [0, 1, 3]`
이 정보는 나중에 `rank()`에서 사용합니다.

## 5. 힌트 ③ — Determinant

```python
def det(A):
    ...
```

먼저 조건을 확인하세요. 행렬식은 어떤 행렬에서 정의되는가?
(힌트: 행 개수 == 열 개수)

행렬을 가우스 소거해서

```
[ * * * ]
[ 0 * * ]
[ 0 0 * ]
```

형태로 만들었다고 생각하세요. 이 행렬의 행렬식은

$$\det(U) = u_{11}\,u_{22}\,u_{33}$$

즉 **대각 원소의 곱**입니다.

단, 행 교환을 했다면 주의해야 합니다. 행 교환 1번에 $\det \rightarrow -\det$,
2번이면 $\det \rightarrow +\det$. 따라서 최종적으로

$$\det(A) = (-1)^{\text{행 교환 횟수}} \times \text{대각 원소의 곱}$$

입니다.

힌트: `row_echelon()`에서 이미 필요한 정보를 반환하도록 만들었다면
`det()`에서 그대로 재사용할 수 있습니다.

## 6. 힌트 ④ — Gauss Elimination

```python
def gauss_eliminate(A, b, pivoting=True, verbose=False):
    ...
```

목표: $Ax = b$ 를 직접 풀어보세요.

**Step 1. 첨가행렬 만들기**

예를 들어

```
2x + y = 5
x + 3y = 6
```

이라면

```
[ 2  1 | 5 ]
[ 1  3 | 6 ]
```

즉 $[A\,|\,b]$ 를 만듭니다.

힌트: `np.hstack(...)`

**Step 2. 가우스 소거**

앞에서 만든 `row_echelon()`과 거의 같은 방식입니다.

```
[ * * | * ]
[ 0 * | * ]
```

형태까지 만드세요. 중요한 점: 이번에는 **b도 함께 소거해야 합니다.**
따라서 $[A\,|\,b]$ 전체를 행 연산해야 합니다.

**Step 3. 후진대입**

소거가 끝났다고 합시다.

```
[ 2  3 | 8  ]
[ 0  4 | 12 ]
```

마지막 행부터 계산합니다. 먼저 $4x_2 = 12$ 에서 $x_2 = 3$.
그 다음 위로 올라가면 $2x_1 + 3x_2 = 8$ 인데 이미 $x_2$를 알고 있으므로

$$x_1 = \frac{8 - 3x_2}{2}$$

코드로 옮길 때: 변수는 뒤에서부터 구합니다 (`x[n-1]`, `x[n-2]`, ..., `x[0]`).
현재 변수보다 뒤에 있는 변수들은 이미 계산되어 있으므로

$$x_i = \frac{b_i - \text{이미 알고 있는 항들의 합}}{a_{ii}}$$

형태로 구현하세요.

## 7. 힌트 ⑤ — Gauss-Jordan 역행렬

```python
def inverse_gauss_jordan(A):
    ...
```

이번에는 연립방정식을 풀지 않습니다.
목표는 $[A\,|\,I]$ 를 $[I\,|\,A^{-1}]$ 로 바꾸는 것입니다.

**Step 1. 단위행렬 붙이기**

예를 들어

```
A = [ 2  1 ]
    [ 1  1 ]
```

이면

```
[A | I] = [ 2  1 | 1  0 ]
          [ 1  1 | 0  1 ]
```

을 만듭니다.

힌트: `np.eye(n)`, `np.hstack(...)`

**Step 2. 피벗 찾기**

가우스 소거와 동일합니다. 피벗을 찾고, 필요하면 행을 교환합니다.
단, 이번에는 피벗을 찾은 뒤 추가 작업이 필요합니다.

**Step 3. 피벗을 1로 만들기**

예를 들어 `[ 2  4 | ... ]` 라면 $R_1 \leftarrow \frac{1}{2}R_1$ 하여
`[ 1  2 | ... ]` 으로 만듭니다. 즉, 현재 피벗을 1로 만듭니다.

**Step 4. 피벗의 위아래를 모두 0으로**

가우스 소거에서는 피벗 **아래**만 0으로 만들었습니다.
가우스-조던에서는 피벗 **위와 아래**를 모두 0으로 만듭니다.

예를 들어

```
[ 1  2 ]
[ 0  1 ]
```

에서 두 번째 피벗을 기준으로 첫 번째 행의 2도 제거하면

```
[ 1  0 ]
[ 0  1 ]
```

**최종 목표**

반복해서 행 연산을 수행한 결과 $[A\,|\,I]$ 가 $[I\,|\,A^{-1}]$ 가 되어야 합니다.
따라서 마지막에는 오른쪽 절반만 반환하면 됩니다.

힌트: 전체 행렬의 열 개수는 $2n$. 왼쪽 $n$개 열이 $I$, 오른쪽 $n$개 열이 $A^{-1}$.

## 8. 다섯 함수의 관계

이번 과제는 사실 다섯 개의 완전히 다른 알고리즘을 구현하는 것이 아닙니다.

```
                행 연산
                   │
                   ▼
            row_echelon()
                   │
      ┌────────────┼────────────┐
      ▼            ▼            ▼
   rank()        det()    gauss_eliminate()
 (피벗 개수)  (대각 곱×부호)     │
                                ▼
                            후진대입

[A | I] ──── Gauss-Jordan ────▶ [I | A⁻¹]
```
