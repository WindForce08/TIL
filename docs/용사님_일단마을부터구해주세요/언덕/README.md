# 🌾 [ 살랑바람 언덕 ]

```
     🌬️  /\  
        /  \    시원한 바람이 솔솔 불어오는 
       /____\   전망 좋은 언덕입니다.
```

시원하고 청량한 바람이 불어오는 탁 트인 언덕입니다.  
마을 전체와 남쪽 푸른 숲, 퐁당퐁당 흘러가는 강줄기가 한눈에 내려다보입니다.

이곳 언덕 위에는 천천히 날개가 돌아가는 커다란 풍차 하나가 서 있습니다.
