# 🌬️ [ 삐걱이는 풍차 ]

```
    / \
   /   \    천천히 날개가 돌아가는 오래된 풍차 안입니다.
  /_____\   노파 한 분이 군고구마를 찌며 차를 마시고 계십니다.
```

천천히 날개가 돌아가는 삐걱이는 오래된 풍차 안입니다.  
안으로 들어가 보니 수상한 할머니 한 분이 군고구마를 구우시며 차를 마시고 계십니다.

> 👵 **수상한 할머니**:  
> *"허허, 어서 오게나 용사. 세상의 끝을 보러 왔는가?"*  
> *"아니면 내가 구운 달콤한 군고구마를 뺏어 먹으러 왔는가? 🍠"*

---
