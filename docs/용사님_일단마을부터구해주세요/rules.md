# 🎮 《용사님, 일단 마을부터 구해주세요》 게임 규칙 및 가이드 (`rules.md`)

> **"어느 날 아침 눈을 뜬 당신, 주머니엔 동전 12개와 촌장님의 편지 한 장... 그리고 길에서 주운 돌멩이?"**  
> 본 게임은 터미널 명령어(`cd`, `cat`, `mv` 등) 또는 파일 탐색기를 이용해 폴더와 텍스트 파일을 넘나들며 즐기는 **폴더 선택형 텍스트 RPG**입니다.

---

## 📜 1. 게임 시놉시스 (Synopsis)

당신은 기억이 약간 상실된 방랑 용사입니다.  
아침에 눈을 뜨니 주머니에는 **12 Gold**와 작은 종이 한 장이 들어 있습니다.

> *"용사님께. 마을에 와주셔서 정말 다행이에요. 큰일이 하나 생겼답니다. - 작은마을 촌장 드림"*  
> *(종이 뒷면: "참고로 빵집은 맛있어요.")*

용사님! 마을로 가서 마을 사람들을 도와주고, 마을을 위협(?)하는 여러 사건들을 해결해 주세요!

## 🗺️ 2. 세계 지도 & 폴더 구조 (Map Directory Structure)

게임은 아래와 같은 폴더 구조로 이루어져 있습니다. 각 폴더는 하나의 **장소**이며, 폴더 내부의 `README.txt`는 해당 장소의 **풍경과 사건**을 담고 있습니다.

│   ├── 🏠 촌장집/ (📜 README.txt)  # 퀘스트 수주 및 사건 제보

├── 🌲 숲/
│   ├── 📜 README.txt            # 푸른 이끼 숲
│   ├── 🐰 토끼굴/ (📜 README.txt)  # 사과를 그리워하는 토끼

## 🕹️ 3. 기본 조작법 (How to Play)

### 💻 A. 터미널(CLI) 환경에서 플레이할 때

| 행동 | Linux / macOS | Windows (CMD/PowerShell) | 설명 |
| :--- | :--- | :--- | :--- |
| **장소 이동** | `cd <폴더명>` | `cd <폴더명>` | 원하는 폴더(장소)로 이동합니다. (예: `cd 작은마을/빵집`) |
| **주위 둘러보기** | `ls` 또는 `ls -l` | `dir` | 현재 위치의 건물, Sub폴더, 파일 목록을 확인합니다. |
| **대화 / 읽기** | `cat <파일명>` | `type <파일명>` | `README.txt`, NPC 대화 파일 내용 등을 읽습니다. |
| **아이템 습득** | `mv <아이템.txt> ../플레이어/가방/` | `move <아이템.txt> ..\플레이어\가방\` | 발견한 아이템(.txt)을 가방 폴더로 이동시킵니다. |
| **아이템 사용/소모** | `rm 플레이어/가방/<아이템.txt>` | `del 플레이어\가방\<아이템.txt>` | 사용하거나 먹은 아이템 파일을 삭제합니다. |
| **상태 갱신** | `nano 플레이어/상태.txt` | `notepad 플레이어\상태.txt` | HP, 소지금, 진행 퀘스트 내용을 에디터로 직접 수정합니다. |
| **상위 폴더 이동** | `cd ..` | `cd ..` | 이전 장소(상위 폴더)로 돌아갑니다. |

---

### 📂 B. 파일 탐색기(GUI) 환경에서 플레이할 때

1. **이동**: 폴더를 더블 클릭하여 입장합니다.
2. **조사 & 대화**: `README.txt` 또는 `.txt` 파일을 텍스트 편집기(메모장, VS Code 등)로 열어 내용을 확인합니다.
3. **아이템 습득**: 아이템 파일(`.txt`)을 마우스 드래그 앤 드롭으로 `플레이어/가방/` 폴더로 이동시킵니다.
4. **상태 관리**: `플레이어/상태.txt` 파일을 열어 HP, 골드, 진행 퀘스트 상태를 에디터로 갱신 및 저장합니다.

---

### 📱 C. 모바일 GitHub (앱 & 브라우저) 환경에서 플레이할 때

1. **탐험 & 대화**: 
   - GitHub 앱 또는 스마트폰 브라우저에서 리포지토리를 터치하여 폴더(`작은마을`, `숲` 등) 간을 자유롭게 이동합니다.
   - `README.txt` 및 NPC/장소 `.txt` 파일을 터치하여 스토리를 읽습니다.
2. **상태 관리 (`상태.txt`)**: 
   - `플레이어/상태.txt` 파일 우상단의 **연필(✏️) 편집 버튼**을 눌러 HP, Gold, 진행 퀘스트를 수정한 뒤 **Commit**하여 저장합니다.
3. **아이템 관리**:
   - **앱**: `플레이어/가방/` 폴더에서 **파일 생성(+)**으로 획득한 아이템 파일을 만들거나 파일 수정으로 보유 아이템을 관리합니다.
   - **모바일 브라우저 / Codespaces**: 모바일 웹 브라우저(Safari/Chrome)로 접속 시 파일 삭제가 수월하며, **GitHub Codespaces**를 사용하면 모바일에서도 웹 터미널로 CLI 명령어(`cd`, `cat`, `mv`) 플레이가 가능합니다!

## ⚙️ 4. 게임 핵심 규칙 (Core Rules)

### 1️⃣ 탐험 및 조사 (Exploration)
- 새로운 폴더에 진입하면 가장 먼저 `README.txt`를 읽으세요.
- 장소에 따라 선택지나 힌트, 숨겨진 요소가 기재되어 있습니다.

### 2️⃣ 퀘스트와 이야기 (Quests)
- 시작 직후 `작은마을/촌장집/README.txt`를 확인하여 촌장님의 부탁을 들으세요.
- 촌장님의 3가지 고민:
  1. 숲에 나타난 **어제보다 3cm 커진 슬라임** 👾
  2. 마을의 보물 **'마을에서 가장 큰 감자'**의 행방 🥔
  3. **우물 속에서 들려오는 의문의 소리** 🕳️

### 3️⃣ 거래 및 소지금 (Economy & Gold)
- 빵집(`달콤고소 빵집`)이나 잡화점(`네잎클로버 잡화점`)에서 아이템 구매 시, 소지금(`Gold`)을 차감하고 구매한 아이템을 `플레이어/가방/` 폴더로 가져옵니다.
- 💵 **초기 소지금**: `12 Gold`

### 4️⃣ 체력과 아이템 사용 (HP & Items)
- **용사님 HP**: 기본 `30 / 30`
- 빵이나 물약, 사탕 등의 회복 아이템을 사용하면 해당 체력만큼 `플레이어/상태.txt`에서 HP를 더해 갱신하고, 아이템 파일은 가방에서 삭제합니다.
- 여관에서 5 Gold를 지불하면 숙박하여 HP를 전액 회복할 수 있습니다.

### 5️⃣ 마을 안전 수칙 (Safety Rule)
- ⚠️ **주의**: *길에서 주운 돌은 함부로 먹지 마세요.* (먹는 행동은 용사님의 명예와 위장에 좋지 않습니다!)

## 💡 5. 깨알 플레이 팁 (Tips & Easter Eggs)

- 🍞 **빵집 주인과의 인연**: 빵집 주인은 정이 많아서 용사님을 볼 때마다 빵을 덤으로 얹어주려고 합니다. (`빵 +1`)
- 🐈 **네 번째 고양이의 행방**: 마을 주민들은 고양이가 4마리라고 주장하지만 실제 관측되는 건 3마리입니다. 4번째 고양이는 과연 어디에 있을까요?
- 🍎 **토끼의 식성**: 숲의 토끼는 당근을 좋아할 것 같지만... 의외로 빨간 사과 냄새를 그리워합니다.
- 👵 **풍차의 수상한 할머니**: 세상의 비밀보다는 방금 구운 군고구마 나누어 먹기를 훨씬 즐기시는 분입니다.
- 🎣 **낚시터의 돌멩이**: 낚싯대가 있다면 강가 낚시터에서 새로운 무언가를 낚을 수도 있습니다!
