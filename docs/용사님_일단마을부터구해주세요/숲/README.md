# 🌲 [ 푸른 이끼 숲 ]

```
   🌲  🍄  🌳   울창하지만 맑고 따스한 햇살이
  🌲  🐰  🌲   나뭇잎 사이로 내리쬐는 아름다운 숲입니다.
```

울창하지만 밝은 햇살이 드는 따스하고 조용한 숲입니다.  
바람이 불 때마다 나뭇잎들이 사각사각 소리를 내며 흔들립니다.

> ⚠️ **숲속 주의사항**:  
> 숲 바닥에 알록달록한 버섯과 이쁜 돌멩이들이 떨어져 있습니다.  
> **함부로 집어 먹지 마세요!** *(특히 알록달록한 버섯과 돌!)*
