# 🌳 [ 천년 묵은 오래된 나무 ]

```
       ,@@@@@@@,
     ,,;;;  ;;;;;;,,
    ;;;;;  🔑  ;;;;;    가지 위에 탐스러운 사과 하나가 걸려 있고
     ;;;;;    ;;;;;     밑동에는 자물쇠 달린 구멍이 보입니다.
        |||||||
```

줄기가 대단히 굵고 웅장한 거대한 옛나무입니다.

---

## 🔍 조사 결과

1. 🔑 **나무 밑동의 자물쇠 구멍**:
   - 나무 밑동에는 조그만 빈 공간(구멍)이 있고 고풍스러운 자물쇠가 달려 있습니다.
   - `'오래된 열쇠'`가 있다면 열어볼 수 있을 것 같습니다.
   - [오래된열쇠 아이템 정보 보기](../../아이템/오래된열쇠.txt)
2. 🍎 **빨갛게 잘 익은 사과**:
   - 나무 가지 위에 빨갛고 잘 익은 사과 하나가 아슬아슬하게 걸려 있습니다.
   - 사과를 따서 숲의 [토끼굴](../토끼굴/README.md)에 있는 토끼에게 가져다주면 좋아할 것 같습니다!
