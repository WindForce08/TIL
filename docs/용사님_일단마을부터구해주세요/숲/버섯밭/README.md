# 🍄 [ 알록달록 버섯밭 ]

```
   👾 (냠냠)  버섯 사이로 커다란 형체 하나와
  🍄 🌾 🍄   잃어버린 밀가루 포대가 보입니다.
```

다양한 색상의 버섯들이 화려하게 자라고 있는 알록달록한 밭입니다.

---

## 🔍 발견된 것들

1. 🌾 **잃어버린 밀가루 포대**:
   - 버섯 뒤에 빵집 주인이 잃어버렸다고 한 밀가루 포대 하나가 수줍게 숨겨져 있습니다!
   - 획득 시 빵집 주인에게 가져다주면 좋은 일이 생길 것 같습니다.
2. 👾 **어제보다 3cm 커진 거대 슬라임**:
   - 촌장님이 경고하신 커다란 형체(슬라임)가 버섯을 냠냠 맛있게 먹고 있습니다.
   - 슬라임은 덤벼들지 않고 대단히 평화로워 보입니다. 얌전히 버섯을 먹는 중입니다.
3. 🍬 **[회복 사탕 발견]**:
   - 풀밭에서 회복 사탕 하나가 떨어져 있습니다.
   - [회복사탕 아이템 정보 보기](../../아이템/회복사탕.txt)
