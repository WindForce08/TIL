# 🏘️ [ 작은 마을 ]

```
       ~  ~  ~
     [🏠] [🍞] [🏪]   사람이 열 명 정도 사는 작은 마을입니다.
    [🛏️]  (🐈)  [🕳️]   고양이가 세 마리 한가롭게 햇살을 쬐고 있습니다.
```

사람이 열 명 정도 사는 아기자기하고 자그마한 마을입니다.  
고양이가 세 마리 기분 좋게 졸고 있습니다.

> 🐱 **마을의 수수께끼**: 마을 사람들은 고양이가 **네 마리**라고 주장합니다.  
> 하지만 아무도 네 번째 고양이를 눈앞에서 직접 본 적은 없습니다...

마을은 아주 평화로워 보입니다.  
너무 평화로워서 조금 불안할 정도입니다.
