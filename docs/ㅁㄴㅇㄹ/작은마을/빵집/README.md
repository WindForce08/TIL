# 🍞 [ 달콤고소 빵집 ]

```
   (  )   (  )
  (____) (____)  갓 구운 빵 냄새가 가게 안 가득 훈훈하게 피어오릅니다.
```

고소한 버터 냄새와 따스한 오븐 열기가 가득 피어오르는 달콤한 빵집입니다.

> 👩‍🍳 **빵집 주인**:  
> *"어서 오세요 용사님! 방금 갓 구운 따끈따끈한 빵이 나왔어요!"*  
> *"어머, 용사님 모험하느라 고생 많으시죠? 이건 서비스예요! (빵 +1)"*

---

## 🛒 판매 상품 목록

| 상품명 | 가격 | 회복 효과 | 설명 |
| :--- | :--- | :--- | :--- |
| 🍞 **갓 구운 식빵** | `3 Gold` | HP **+15** 회복 | 겉은 바삭하고 속은 촉촉한 갓 구운 식빵 |
| 🍓 **딸기잼 소보로** | `4 Gold` | HP **+20** 회복 | 붉고 달콤한 잼이 들어간 빵 (딸기 재료는 버섯밭 근처 소문) |

> 💡 **특이사항**: 빵집 주인은 손이 매우 커서 용사님을 볼 때마다 계속 덤으로 빵을 얹어주려고 합니다.
