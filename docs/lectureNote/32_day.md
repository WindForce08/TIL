# PID 적분과 컴퓨터적 사고

## 1. 물리학에서 생각하는 적분

물리학이나 수학에서는 적분을 **연속적으로 누적되는 양**으로 생각합니다.

예를 들어 모터의 오차가 시간에 따라 계속 변한다면,

```text
시간 전체에 걸쳐 발생한 오차를 모두 누적한다
```

가 적분의 의미입니다.

즉 개념적으로는:

```text
오차가 발생
→ 시간 동안 누적
→ 지금까지 누적된 총량
```

입니다.

---

## 2. 하지만 컴퓨터는 시간을 연속적으로 계산하지 않는다

컴퓨터는 현실의 시간을 그대로 계산하지 않습니다.

PID 프로그램이 0.1초마다 실행된다고 하면:

```text
0.0초
→ 오차 측정

0.1초
→ 오차 측정
→ 계산

0.2초
→ 오차 측정
→ 계산

0.3초
→ 오차 측정
→ 계산
```

처럼 **일정한 시간 간격마다 현재 상태를 읽고 계산**합니다.

따라서 컴퓨터에서는 적분을 다음과 같은 방식으로 처리합니다.

```text
누적값 = 기존 누적값 + 현재 오차 × 시간 간격
```

코드로 표현하면:

```python
integral = integral + error * dt
```

이것이 컴퓨터에서 적분을 구현하는 가장 기본적인 형태입니다.

---

## 3. 문제의 A는 무엇인가?

문제에서 등장한 `A`는 새로운 물리량이 아닙니다.

그냥 **지금까지 누적된 적분 결과를 저장해 놓은 변수**입니다.

예를 들어:

```text
A = 0.4
```

라고 되어 있다면,

```text
지금까지 오차를 누적한 결과가 0.4이다.
```

라는 뜻입니다.

현재 오차가 1이고 시간 간격이 0.1초라면:

```text
이번에 추가되는 양
= 1 × 0.1
= 0.1

새로운 A
= 기존 A + 이번에 추가되는 양
= 0.4 + 0.1
= 0.5
```

따라서 `A`는 사람이 매번 새로 계산하는 값이 아니라 **PID 프로그램이 계속 가지고 있으면서 업데이트하는 값**이라고 이해하면 됩니다.

---

## 4. 이것이 컴퓨터적인 사고방식이다

PID 프로그램은 매 순간 다음과 같이 생각합니다.

```text
1. 지금 오차가 얼마지?
2. 이전에 오차가 얼마나 누적됐지?
3. 이번 오차를 누적값에 추가하자.
4. 오차가 이전보다 얼마나 변했지?
5. P, I, D를 각각 계산하자.
6. 세 값을 더해서 모터에 명령을 보내자.
7. 다음 계산을 위해 현재 상태를 저장하자.
8. 다시 처음으로 돌아간다.
```

즉 PID는 한 번 계산하고 끝나는 공식이 아니라 **계속 반복되는 프로그램**입니다.

---

## 5. P, I, D를 컴퓨터 관점에서 보면

### P

```text
현재 오차가 얼마나 큰가?
```

```python
P = Kp * error
```

현재 순간의 오차를 보고 바로 반응합니다.

---

### I

```text
지금까지 오차가 얼마나 쌓였는가?
```

```python
integral = integral + error * dt
I = Ki * integral
```

과거부터 현재까지의 오차를 기억합니다.

---

### D

```text
오차가 지금 얼마나 빠르게 변하고 있는가?
```

```python
D = Kd * (error - previous_error) / dt
```

현재 오차와 바로 이전 오차를 비교합니다.

그래서 D를 계산하려면 **이전 오차를 기억하고 있어야 합니다.**

---

## 6. 결국 PID 프로그램은 "기억"을 사용한다

이 부분이 수학 공식만 볼 때와 가장 다른 부분입니다.

컴퓨터는 PID를 계산하면서 과거의 정보를 변수에 저장합니다.

```text
previous_error
integral
```

예를 들어:

```text
previous_error = 2
integral = 0.4
```

를 가지고 있다가 새로운 오차 `1`이 들어오면:

```text
현재 error = 1

integral
= 0.4 + 1 × 0.1
= 0.5

D
= 현재 오차 1 - 이전 오차 2
= -1
```

처럼 계산합니다.

그리고 계산이 끝나면:

```text
previous_error = 1
```

로 업데이트합니다.

다음 순간에는 이 `1`이 다시 **이전 오차**가 됩니다.

# 7. 물리학과 컴퓨터공학의 차이

| 관점 | 물리학/수학 | 컴퓨터 |
|---|---|---|
| 시간 | 연속적인 시간 | 일정한 주기의 샘플 |
| 적분 | 전체 시간에 걸친 누적 | 매 주기마다 누적 |
| 현재 상태 | 수식으로 표현 | 변수에 저장 |
| 과거 정보 | 수학적으로 포함 | 변수에 직접 저장 |
| 계산 | 연속적인 모델 | 반복문 |
| 실제 구현 | 이상적인 계산 | 측정 → 계산 → 출력 반복 |

따라서 **수학적 PID 공식이 틀린 것이 아니라, 컴퓨터가 그것을 실행할 수 있는 형태로 바꾸는 과정이 필요한 것**입니다.

## 8. 이번 실습에서 가져가야 할 핵심

```text
물리적 세계
    ↓
센서가 현재 상태 측정
    ↓
현재 오차 계산
    ↓
컴퓨터가 P / I / D 계산
    ↓
출력 제한
    ↓
모터에 명령
    ↓
모터가 움직임
    ↓
다시 센서가 측정
    ↓
반복
```

그리고 I항만 보면:

```text
기존 누적값
    +
현재 오차 × 시간 간격
    ↓
새로운 누적값
    ↓
Ki를 곱함
    ↓
I항
```

**이번에 `A가 어디서 튀어나왔냐`, `적분할 게 없는데 뭘 적분하냐`라고 느꼈던 게 오히려 정확한 문제의식입니다.**

수학에서는 `적분`이라는 연산으로 표현하지만, 컴퓨터에서는 결국

```python
integral += error * dt
```

라는 **상태 업데이트 작업**으로 구현됩니다.

앞으로 PID 코드를 볼 때는 공식을 먼저 외우기보다 **"이 변수는 과거의 무엇을 기억하고 있고, 이번 주기에 무엇을 업데이트하는가?"**를 먼저 보면 훨씬 이해하기 쉬울 겁니다.
