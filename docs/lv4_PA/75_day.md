# 2. AI의 학습(Training)

## 2-1. 학습이란?

학습은 정답에 가까운 결과를 출력할 수 있도록 모델의 가중치(Weight)를 수정하는 과정이다.

기본적인 학습 흐름은 다음과 같다.

```text
입력 데이터 + 정답 데이터
          ↓
      예측값 계산
          ↓
       손실 계산
          ↓
       기울기 계산
          ↓
       가중치 수정
          ↓
       반복 학습
```

각 개념의 역할은 다음과 같다.

| 개념 | 역할 |
|---|---|
| Input | 모델에 입력하는 데이터 |
| Label | 입력 데이터에 대응하는 정답 |
| Prediction | 모델이 계산한 예측값 |
| Loss | 예측값과 정답의 차이 |
| Gradient | 가중치를 수정할 방향과 변화율 |
| Weight Update | 기울기를 이용한 가중치 수정 |

## 2-2. 간단한 모델 만들기

다음과 같은 선형 모델을 가정한다.

y_hat = wx

- x: 입력값
- w: 가중치
- y_hat: 예측값
- y: 실제 정답

예제 조건:

```text
입력값 x = 2
정답 y = 6
초기 가중치 w = 1
```

예측값 계산:

y_hat = 1 × 2 = 2

실제 정답은 6이므로 예측이 틀렸다.

## 2-3. 손실 함수(Loss Function)

손실은 모델의 예측값과 실제 정답 사이의 차이를 숫자로 표현한 것이다.

이번에는 제곱오차를 사용한다.

L = (y_hat - y)^2

값을 대입하면 다음과 같다.

L = (2 - 6)^2 = 16

현재 손실은 16이다.

손실이 작아질수록 예측값이 정답에 가까워진다.

단, 손실 함수의 종류에 따라 계산 방식은 달라질 수 있다.

## 2-4. 가중치와 손실의 관계

모델은 다음과 같다.

y_hat = wx

입력값 x=2, 정답 y=6을 유지하면 다음과 같이 표현할 수 있다.

L(w) = (2w - 6)^2

이 식은 가중치 w에 따라 손실이 어떻게 달라지는지 보여준다.

| 가중치 w | 예측값 | 손실 |
|---:|---:|---:|
| 0 | 0 | 36 |
| 1 | 2 | 16 |
| 2 | 4 | 4 |
| 2.5 | 5 | 1 |
| 3 | 6 | 0 |
| 4 | 8 | 4 |

가중치가 3일 때 손실이 0이 된다.

즉, 이 예제에서 최적의 가중치는 3이다.

가중치를 변화시키면 손실도 변화한다. 학습은 손실이 작아지는 가중치를 찾아가는 과정이다.

## 2-5. 기울기(Gradient)

기울기는 손실 함수가 가중치 변화에 따라 얼마나 변하는지 나타낸다.

앞의 손실 함수:

L(w) = (2w - 6)^2

가중치에 대해 미분하면 다음과 같다.

dL/dw = 8w - 24

현재 가중치가 1이라면:

dL/dw = 8(1) - 24 = -16

기울기는 -16이다.

기울기의 부호는 가중치를 어느 방향으로 움직여야 손실이 줄어드는지 알려준다.

- 음수(-): 가중치를 높이는 방향으로 이동
- 양수(+): 가중치를 낮추는 방향으로 이동
- 0: 해당 지점의 순간 기울기가 0

## 2-6. 경사하강법(Gradient Descent)

경사하강법은 기울기를 이용하여 손실이 작아지는 방향으로 가중치를 조금씩 수정하는 방법이다.

공식:

w_new = w_old - η × (dL/dw)

- w_old: 기존 가중치
- w_new: 수정된 가중치
- η: 학습률(Learning Rate)
- dL/dw: 가중치에 대한 손실의 기울기

학습률은 가중치를 한 번에 얼마나 이동시킬지 결정한다.

예제 조건:

```text
기존 가중치 = 1
기울기 = -16
학습률 = 0.1
```

계산:

w_new = 1 - 0.1 × (-16)

w_new = 2.6

가중치가 1에서 2.6으로 변경되었다.

새로운 예측값:

y_hat = 2.6 × 2 = 5.2

새로운 손실:

L = (5.2 - 6)^2 = 0.64

손실이 16에서 0.64로 감소했다.

## 2-7. 반복 학습

경사하강법을 반복 적용하면 다음과 같이 변화한다.

| 학습 단계 | 가중치 | 예측값 | 손실 |
|---|---:|---:|---:|
| 시작 | 1.000 | 2.000 | 16 |
| 1회 | 2.600 | 5.200 | 0.64 |
| 2회 | 2.920 | 5.840 | 0.0256 |
| 3회 | 2.984 | 5.968 | 0.001024 |
| 목표 | 3.000 | 6.000 | 0 |

결론:

학습은 입력과 정답을 이용해 손실을 계산하고, 기울기를 구한 뒤, 손실이 줄어드는 방향으로 가중치를 수정하는 과정이다.

# 3. AI의 추론(Inference)

## 3-1. 추론이란?

추론은 학습된 가중치를 이용하여 새로운 입력의 출력값을 계산하는 과정이다.

학습과 달리 일반적인 추론 과정에서는 가중치를 수정하지 않는다.

핵심:

- 학습: 가중치를 최적화한다.
- 추론: 최적화된 가중치를 사용한다.

## 3-2. 학습된 모델을 이용한 추론

앞에서 학습한 모델:

y_hat = wx

학습이 완료되어 최적의 가중치가 3이라고 가정한다.

따라서 추론 모델은 다음과 같다.

y_hat = 3x

새로운 입력값 x=5를 입력한다.

y_hat = 3 × 5 = 15

결과는 15이다.

이 과정에서 가중치는 변경되지 않는다.

## 3-3. 입력값이 바뀌면?

가중치가 3으로 고정되어 있어도 새로운 입력값에 따라 출력은 달라진다.

| 입력값 x | 가중치 w | 출력값 |
|---:|---:|---:|
| 1 | 3 | 3 |
| 2 | 3 | 6 |
| 5 | 3 | 15 |
| 10 | 3 | 30 |
| 100 | 3 | 300 |

가중치는 고정되어 있지만 입력값이 달라지므로 출력값은 계속 달라진다.

중요한 점:

가중치를 고정한다는 것은 가중치를 사용하지 않는다는 뜻이 아니다.

기존에 학습된 가중치를 그대로 계산에 사용하는 것이다.

## 3-4. 학습과 추론 비교

| 구분 | 학습(Training) | 추론(Inference) |
|---|---|---|
| 목적 | 가중치 최적화 | 새로운 데이터 예측 |
| 입력 | 학습 데이터 | 새로운 데이터 |
| 정답 데이터 | 학습에 사용 | 예측 자체에는 불필요 |
| 손실 계산 | 학습에 사용 | 일반적인 추론에는 불필요 |
| 역전파 | 수행 | 수행하지 않음 |
| 가중치 | 변경 | 고정 |
| 결과 | 학습된 모델 | 예측값 |

추가 개념:

일반화(Generalization)는 학습에 사용하지 않았던 새로운 데이터에도 모델이 적절하게 대응하는 능력이다.

# 4. LLM(Large Language Model)

## 4-1. LLM이란?

LLM은 Large Language Model의 약자다.

방대한 텍스트 데이터를 학습하여 언어의 패턴을 익히고, 다음에 올 토큰을 예측하는 대규모 신경망 모델이다.

대표적인 작업:

- 문장 생성
- 질문 답변
- 문장 요약
- 번역
- 코드 생성
- 문맥 파악

LLM은 기본적으로 숫자를 계산하는 신경망이다.

사람이 사용하는 단어를 그대로 계산하는 것이 아니라 토큰을 숫자 벡터로 변환하여 처리한다.

## 4-2. 토큰(Token)

토큰은 LLM이 텍스트를 처리하기 위해 분리한 기본 단위다.

단어 하나가 반드시 토큰 하나인 것은 아니다.

예시 문장:

"나는 로봇을 좋아한다."

설명을 위한 토큰 분리 예시:

```text
나는 / 로봇 / 을 / 좋아 / 한다
```

실제 토큰 분리는 사용하는 토크나이저에 따라 달라진다.

## 4-3. 임베딩(Embedding)

토큰을 컴퓨터가 계산할 수 있는 숫자 벡터로 변환하는 과정이다.

예시:

| 토큰 | 임베딩 |
|---|---|
| 나는 | [0.2, 0.5, 0.1] |
| 로봇 | [0.8, 0.3, 0.7] |
| 을 | [0.1, 0.2, 0.4] |
| 좋아 | [0.6, 0.9, 0.2] |

실제 LLM은 훨씬 높은 차원의 벡터를 사용한다.

핵심:

토큰을 숫자 벡터로 변환해야 신경망이 행렬 연산을 수행할 수 있다.

# 5. Self-Attention

## 5-1. Self-Attention이란?

Self-Attention은 문장 안에 있는 토큰들이 서로를 얼마나 참고해야 하는지 계산하는 메커니즘이다.

쉽게 말하면:

현재 토큰의 의미를 파악하기 위해 문장 안의 다른 토큰들을 살펴보고, 어떤 정보가 중요한지 계산하는 과정이다.

예시:

"철수가 사과를 먹었다. 그것은 맛있었다."

여기서 '그것'은 앞 문장의 '사과'를 가리킨다.

사람은 앞 문맥을 참고하여 의미를 파악한다.

Self-Attention도 토큰 사이의 관계를 계산하여 문맥 정보를 반영한다.

단, 실제 Self-Attention은 단순한 단어 검색이 아니라 벡터 연산을 통해 관계를 수치적으로 계산한다.

# 6. Q, K, V

Self-Attention의 핵심 구성 요소다.

| 기호 | 이름 | 역할 |
|---|---|---|
| Q | Query | 내가 무엇을 찾고 있는가? |
| K | Key | 내가 어떤 정보를 가지고 있는가? |
| V | Value | 실제로 전달할 정보는 무엇인가? |

## 6-1. 도서관 비유

- Q: 내가 찾고 싶은 책의 검색어
- K: 각 책에 붙어 있는 색인 또는 키워드
- V: 실제 책에 들어 있는 내용

검색어(Q)와 색인(K)을 비교한다.

관련성이 높은 정보를 찾은 뒤 실제 내용(V)을 가져온다.

## 6-2. Q, K, V는 어떻게 만들어지는가?

Q, K, V는 사람이 직접 지정하는 값이 아니다.

입력 임베딩 행렬에 학습된 가중치 행렬을 곱해서 만들어진다.

수식:

Q = XW_Q

K = XW_K

V = XW_V

각 기호의 의미:

| 기호 | 의미 |
|---|---|
| X | 입력 임베딩 행렬 |
| W_Q | Query를 생성하는 가중치 행렬 |
| W_K | Key를 생성하는 가중치 행렬 |
| W_V | Value를 생성하는 가중치 행렬 |

여기서 이전에 학습했던 가중치 개념이 다시 등장한다.

W_Q, W_K, W_V는 학습 과정에서 최적화되는 파라미터다.

추론 과정에서는 이 가중치 행렬이 고정된다.

하지만 새로운 입력 X가 들어오면 새로운 Q, K, V가 계산된다.

즉, 가중치는 고정되어 있지만 입력에 따라 Q, K, V는 달라진다.

# 7. Attention Score(관계 점수)

## 7-1. 관계 점수란?

Q와 K를 비교하여 토큰 사이의 관련성을 계산한 점수다.

기본 공식:

Score = QK^T / √d_k

여기서:

- Q: Query 행렬
- K: Key 행렬
- K^T: Key 행렬의 전치
- d_k: Key 벡터의 차원 수

## 7-2. 왜 K에 전치 연산 T를 적용하는가?

T는 Transpose의 약자다.

행렬의 행과 열을 서로 바꾸는 연산이다.

예를 들어:

```text
K =
[1 2]
[3 4]
[5 6]
```

전치하면:

```text
K^T =
[1 3 5]
[2 4 6]
```

Q와 K를 행렬로 표현했을 때, 각 토큰의 Query와 모든 토큰의 Key 사이의 내적을 한 번에 계산하기 위해 전치 연산을 사용한다.

QK^T의 결과는 토큰별 관계 점수를 나타내는 행렬이다.

## 7-3. 왜 √d_k로 나누는가?

벡터 차원이 커지면 내적 결과가 커지는 경향이 있다.

점수가 지나치게 커지면 Softmax 결과가 특정 토큰에 과도하게 집중할 수 있다.

이를 방지하고 점수의 크기를 조절하기 위해 √d_k로 나눈다.

# 8. Softmax와 Attention Weight

## 8-1. Softmax란?

Softmax는 여러 점수를 0~1 사이의 값으로 변환하고, 전체 합이 1이 되도록 만드는 함수다.

예시:

Softmax 적용 전 관계 점수:

[1, 2, 0]

Softmax 적용 후:

[0.245, 0.665, 0.090]

| 토큰 | 원래 점수 | Attention Weight |
|---|---:|---:|
| A | 1 | 0.245 |
| B | 2 | 0.665 |
| C | 0 | 0.090 |

해석:

- A의 정보를 24.5% 반영한다.
- B의 정보를 66.5% 반영한다.
- C의 정보를 9.0% 반영한다.

Attention Weight는 각 Value를 얼마나 반영할지 결정하는 비율이다.

주의:

Attention Weight를 실제 언어적 의미의 확률이나 중요도로 그대로 해석해서는 안 된다.

이는 해당 Attention 연산에서 각 Value를 반영하는 비율이다.

# 9. Weighted Sum(가중합)

## 9-1. 가중합이란?

각 토큰의 Value에 Attention Weight를 곱하고 모두 더하는 연산이다.

관계 점수와 Softmax를 통해 어떤 정보를 얼마나 반영할지 결정했다면, 이제 실제 정보인 V를 가져와야 한다.

## 9-2. 숫자 예제

Attention Weight:

[0.245, 0.665, 0.090]

Value:

| 토큰 | Weight | Value |
|---|---:|---:|
| A | 0.245 | 2 |
| B | 0.665 | 4 |
| C | 0.090 | 10 |

가중합 계산:

Output = (0.245 × 2) + (0.665 × 4) + (0.090 × 10)

Output = 0.49 + 2.66 + 0.90

Output = 4.05

이 결과가 가중합이다.

## 9-3. 실제 LLM에서는?

실제 Value는 하나의 숫자가 아니라 여러 차원으로 구성된 벡터다.

예시:

V_A = [2, 1]

V_B = [4, 3]

V_C = [10, 5]

계산:

Output = 0.245V_A + 0.665V_B + 0.090V_C

첫 번째 차원:

0.245 × 2 + 0.665 × 4 + 0.090 × 10 = 4.05

두 번째 차원:

0.245 × 1 + 0.665 × 3 + 0.090 × 5 = 2.80

최종 결과:

Output = [4.05, 2.80]

이것이 문맥 정보를 반영한 새로운 벡터 표현이다.

# 10. Self-Attention 전체 수식

지금까지 배운 과정을 하나의 공식으로 표현할 수 있다.

Attention(Q,K,V) = Softmax(QK^T / √d_k)V

각 부분의 역할:

| 연산 | 의미 |
|---|---|
| QK^T | 토큰 사이의 관계 점수 계산 |
| /√d_k | 점수 크기 조절 |
| Softmax | 관계 점수를 참고 비율로 변환 |
| ×V | 실제 정보에 참고 비율 적용 |
| 결과 | 문맥을 반영한 새로운 벡터 |

전체 과정:

```text
입력 임베딩 X
      ↓
Q, K, V 생성
      ↓
Q와 K 비교
      ↓
Attention Score 계산
      ↓
Softmax
      ↓
Attention Weight 생성
      ↓
Attention Weight × V
      ↓
Weighted Sum
      ↓
최종 Attention Output
```

# 11. Multi-Head Attention과 Transformer

실제 GPT 계열 모델은 Self-Attention을 한 번만 수행하지 않는다.

## 11-1. Multi-Head Attention

여러 개의 Attention Head를 병렬로 사용하여 다양한 관계를 계산한다.

예를 들어 설명하면:

- 한 Head는 문법적인 관계를 학습할 수 있다.
- 다른 Head는 멀리 떨어진 토큰 사이의 관계를 학습할 수 있다.
- 또 다른 Head는 특정 문맥이나 의미적 패턴을 학습할 수 있다.

이것은 이해를 위한 예시이며, 실제 Head의 역할이 항상 명확하게 분리되는 것은 아니다.

## 11-2. Transformer의 전체적인 구성

GPT와 같은 Decoder-only Transformer는 일반적으로 다음 요소들을 반복적으로 사용한다.

1. Token Embedding
2. Positional Information
3. Causal Self-Attention
4. Feed Forward Network
5. Residual Connection
6. Layer Normalization

이러한 Transformer Block을 여러 층 쌓아 모델을 구성한다.

## 11-3. Causal Masking

GPT처럼 다음 토큰을 예측하는 모델은 아직 생성되지 않은 미래의 토큰을 참고하면 안 된다.

따라서 Causal Masking을 적용한다.

예시:

```text
나는 오늘 로봇을 만들었다.

나는       → 나
오늘       → 나, 오늘
로봇을     → 나, 오늘, 로봇을
만들었다   → 나, 오늘, 로봇을, 만들었다
```

현재 토큰보다 뒤에 있는 미래 토큰을 참조하지 못하도록 제한한다.

이것이 GPT 계열 모델의 Autoregressive 생성 구조와 연결된다.

# 13. 오늘 학습에서 반드시 기억할 내용

## 학습과 추론

- 학습은 가중치를 수정하는 과정이다.
- 추론은 가중치를 고정하고 계산하는 과정이다.
- 가중치가 고정되어 있어도 새로운 입력에 따라 출력은 달라진다.

## Self-Attention

- Q는 무엇을 찾을지 결정하는 기준이다.
- K는 Q와 비교하는 대상이다.
- V는 실제로 가져올 정보다.
- Q와 K를 비교하여 관계 점수를 만든다.
- Softmax를 통해 각 Value의 반영 비율을 계산한다.
- 가중합으로 문맥을 반영한 새로운 벡터를 만든다.

## 가장 중요한 공식

학습:

w_new = w_old - η × Gradient

Self-Attention:

Attention(Q,K,V) = Softmax(QK^T / √d_k)V
