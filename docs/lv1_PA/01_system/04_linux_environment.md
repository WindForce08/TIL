# 리눅스 핵심 개념 복습 노트

## 🎯 핵심 요점

- **커널과 사용자 공간**: 리눅스는 커널(하드웨어 관리)과 사용자 공간(애플리케이션)이 명확히 분리되어 있어요.
- **프로세스**: 실행 중인 프로그램의 인스턴스로, 각각 독립적인 메모리 공간을 가져요.
- **파일시스템과 권한**: 모든 것이 파일로 표현되며, 사용자·그룹·기타에 따라 읽기·쓰기·실행 권한이 관리돼요.
- **셸의 역할**: 사용자 명령어를 받아 커널에 전달하는 인터프리터예요.

## 📚 퀴즈에서 배운 핵심 개념

리눅스의 철학 중 하나는 '작은 도구를 조합하라'는 원칙이에요. 이를 가능하게 하는 것이 바로 **파이프**입니다.

파이프는 두 프로세스를 직접 연결해요. 앞선 명령어의 출력 스트림이 뒷 명령어의 입력 스트림으로 즉시 흘러가는 거죠. 이 과정에서 중간 파일을 만들 필요가 없어요. 여러 명령어를 파이프라인처럼 연결하면 복잡한 작업도 간단하고 효율적으로 처리할 수 있어요.

## 💡 헷갈리기 쉬운 지점

파이프(|)와 리다이렉션(>, <)을 헷갈리기 쉬운데, 파이프는 **프로세스 간 연결**이고 리다이렉션은 **파일 입출력**이에요.

## 🔍 헷갈렸던 부분 정리

혹시 파이프가 단순히 '출력을 다음 명령어로 보내는 것'이라고만 생각했다면, 더 깊게 이해해 봅시다. 파이프는 **두 개의 독립적인 프로세스를 커널 차원에서 연결**하는 거예요. 앞 프로세스는 계속 출력하고, 뒷 프로세스는 계속 입력받으면서 동시에 처리돼요. 이는 리눅스의 멀티프로세싱 철학과 깊이 연결된 개념이에요.
