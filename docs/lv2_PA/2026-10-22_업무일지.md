## 6. 생긴 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 레이캐스터 오류 "No prim found at .../lds03_front" | 장면 관리자(InteractiveScene) 없이 쓰면 센서 프레임 prim이 만들어지지 않음 | `cfg.spawn.func(...)`로 직접 생성 |
| "No mesh prims found at /World/Obstacles/front/geometry/material" | 대상 정규식이 하위 prim까지 잡음 | 정규식을 `/World/Obstacles/[^/]+`로 |
| 라이다가 자기 머리를 맞히고 원점이 틀림 | Isaac Lab 3.0이 오프셋 회전을 광선 방향에만 적용하고 시작점에는 안 함 | 시작점을 `start_rot`로 미리 회전, 원점은 URDF 오프셋으로 계산 |
| 제자리 회전 때 바퀴 속도가 튐 | 바퀴 관성이 너무 작음 (감속기 반사 관성 없음) | armature 바퀴 0.005, 팔 0.01 추가 |
| 도감 게시 막힘 | 이전 조직 사용량 한도 | 지금 조직에 새 링크로 게시 |
| BOM 엑셀(xlsx) 못 만듦 | openpyxl 미설치 | 건너뜀, CSV(`BOM_purchased_parts.csv`)는 있음 |
| Bambu CLI segfault | 58판짜리 3MF | 진단용은 30판씩 나눔 |
| KANT 4단계 테스트가 계속 실패 | VS Code에서 저장하지 않음, 그다음 `import math` 빠짐 | Ctrl+S 저장, `import math` 한 줄 추가 (Claude에게 요청) |
