## 3. TeamRobot 6WD 남은 실물 결함 (23:56 ~ 23:58)
- 근거: `6WD_Chassis/design_review.md` (10·11·14 ~ 20절), Isaac Lab · 웹 시뮬레이터 결과. 모두 CAD · URDF 계산값이고 실측은 아님.

| 심각도 | 부위 | 결함 |
|---|---|---|
| 심각 | 퍽 보관함 | 뒤 줄 6칸은 팔이 안 닿음. 앞 줄도 J4 122 ~ 124° 필요 (한계 113°), 바닥 틈 한쪽 1 mm 라 꺼낼 때 걸릴 가능성 큼, 컵 윗벽 1 mm 라 깨지기 쉬움 |
| 심각 | 전복 | 팔을 앞으로 뻗고 500 g 이면 앞 6.0°, 200 g 이면 약 15° |
| 심각 | 팔 처짐 | Position I = 0 이면 J2 0.060 · J3 0.049 rad, 끝점 7.5 ~ 9.5 mm |
| 심각 | 바퀴 고정 | 허브 홈 2.0 < XM430 허브 2.2 mm 로 0.2 mm 뜸, M2x3 물림 0.8 mm |
| 심각 | 지상고 · 배선 | TTL 플러그와 지면 3.75 mm (기준 5 mm), 데이지 체인 불가 (모터 6개에 허브 필요) |
| 중간 | 센서 | LDS-03 좌우 약 28° 사각 · 퍽 (60 mm) 안 보임, TFmini 바닥 반사, 앞 D435 화면에 팔, Arducam 잡는 자리 안 보임 |
| 중간 | 팔 · 손목 | 홈 자세 요 ±137° 에서 프로파일에 닿음, 손목 롤 케이블 꼬임, J4 부하 +84 % |
| 중간 | 구조 · 정비 | 카메라 마스트 336 mm 외팔보 진동, PLA 하판에 모터 직결 (55 ~ 60 °C 부터 물러짐), 한 몸 부품은 깨지면 큰 출력물 재출력 |

- 실측이 필요한 것: 끼움 공차, 나사 (RealSense 브래킷 구멍, D435 1/4-20 깊이), 전체 · 퍽 무게, 배터리 (LB-012 ×2) 용량, LDS-03 0° 방향, Jetson USB 포트 수 (필요 7개), 모터 발열.
