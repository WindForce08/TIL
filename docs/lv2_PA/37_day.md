### 구조 이해

```text
             입구 38 × 38
          ┌────────────┐
         /              \
        /                \
       /                  \
      │                    │
      │                    │
      └────── 32 × 32 ────┘
             ↑
           35 mm
             ↓
        ────────────
```

- 사방이 막힌 구조

- 내부 벽은 아래로 갈수록 좁아지는 깔때기 형태
- 전체 높이 40 mm 중 포켓 깊이 35 mm이므로 바닥 두께는 5 mm

## 2. 경사각 계산

입구와 바닥의 차이:

```text
38 - 32 = 6 mm
```

양쪽으로 동일하게 좁아지므로 한쪽 이동량:

```text
6 / 2 = 3 mm
```

깊이:

```text
35 mm
```

따라서 내부 벽의 경사각:

```text
atan(3 / 35) ≈ 4.90°
```

### FreeCAD 설정

```text
Pocket Length = 35 mm
Taper Angle   = 4.90°
```

이렇게 설정하면:

```text
입구: 38 × 38 mm
      ↓
   35 mm 깊이
      ↓
바닥: 32 × 32 mm
```

가 되도록 설계할 수 있음.

## 4. 3D 프린팅 준비

### 출력 방향

현재 구조 그대로:

```text
       열린 입구
      ┌────────┐
     /          \
    /            \
   │              │
   │              │
   └──────────────┘
   ████████████████
       베드
```

- **5 mm 바닥면을 프린터 베드에 배치**
- 포켓 입구가 위쪽을 향하도록 출력
- 내부 경사면 때문에 **서포트 없이 출력하는 방향**으로 계획

### 1차 출력 설정안

PLA 기준:

| 설정 | 값 |
|---|---:|
| Layer Height | 0.20 mm |
| Wall Loops | 3 |
| Infill | 15~20% |
| Support | 사용하지 않음 |
| Brim | 우선 사용하지 않음 |
