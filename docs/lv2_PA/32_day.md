# TIL — PID 적분과 컴퓨터적 사고방식

> 학습 주제: PID 제어의 적분(I)항 이해  
> 핵심 키워드: `오차`, `적분`, `누적값`, `샘플링`, `P/I/D`, `제어 출력`

---

## 1. 오늘 배운 것

PID 제어에서 적분(I)항을 공부하면서 **수학/물리학에서 사용하는 적분과 컴퓨터에서 구현하는 적분의 사고방식이 다르다**는 것을 이해했다.

수학에서는 적분을 연속적인 시간 동안의 누적으로 표현하지만, 컴퓨터에서는 시간을 연속적으로 계산하지 않고 **일정한 주기마다 측정하고 계산하면서 누적값을 업데이트한다.**

---

# 2. PID의 기본 구조

PID는 현재 오차를 이용해서 제어 출력을 계산한다.

```text
목표값
  ↓
현재 상태 측정
  ↓
오차 계산
  ↓
┌───────────────┐
│ P             │
│ I             │
│ D             │
└───────┬───────┘
        ↓
    P + I + D
        ↓
   출력 제한
        ↓
      모터
        ↓
    다시 측정
        ↓
      반복
```

즉 PID는 한 번 계산하는 공식이 아니라 **계속 반복해서 실행되는 제어 알고리즘**이다.

---

# 3. P, I, D의 차이

## P — 현재 오차

P는 현재 오차가 얼마나 큰지를 본다.

```text
현재 오차가 크다
→ 강하게 반응

현재 오차가 작다
→ 약하게 반응
```

코드에서는 기본적으로 다음과 같이 표현할 수 있다.

```python
P = Kp * error
```

P는 **현재**를 본다.

---

## I — 지금까지 쌓인 오차

I는 과거부터 현재까지 오차가 얼마나 누적되었는지를 본다.

쉽게 말하면:

```text
"지금까지 계속 오차가 있었는데
그걸 전부 합치면 얼마나 되지?"
```

이다.

컴퓨터에서는 보통 다음과 같이 구현한다.

```python
integral = integral + error * dt
I = Ki * integral
```

I는 **과거부터 현재까지의 누적**을 본다.

---

## D — 오차의 변화

D는 오차 자체보다 **오차가 얼마나 빠르게 변하고 있는지**를 본다.

```python
D = Kd * (error - previous_error) / dt
```

따라서 D는 현재 오차뿐만 아니라 **이전 오차를 기억하고 있어야 한다.**

---

# 4. 적분에서 가장 헷갈렸던 `A`

문제에서 다음과 같은 값이 주어졌다.

```text
A = 0.4
현재 오차 = 1
dt = 0.1
```

처음에는 `A`가 공식에서 갑자기 등장한 것처럼 보였다.

하지만 `A`는 새로운 물리량이 아니다.

```text
A = 지금까지 누적된 적분 결과
```

를 저장하기 위해 사용하는 **변수**라고 이해하면 된다.

즉,

```text
A = 0.4
```

라는 것은

```text
"이전까지 오차를 누적한 결과가 0.4였다."
```

라는 뜻이다.

---

# 5. 컴퓨터에서 적분하는 방법

컴퓨터는 시간을 연속적으로 계산하지 않는다.

예를 들어 PID가 `0.1초`마다 실행된다고 하면:

```text
0.0초 → 측정 → 계산
0.1초 → 측정 → 계산
0.2초 → 측정 → 계산
0.3초 → 측정 → 계산
...
```

이런 방식으로 동작한다.

따라서 적분값을 매 주기마다 다음과 같이 업데이트한다.

```python
integral = integral + error * dt
```

또는 짧게:

```python
integral += error * dt
```

---

# 6. 문제의 적분 계산

기존 누적값이:

```text
A = 0.4
```

이고,

```text
현재 오차 = 1
dt = 0.1
```

이라면 이번 계산에서 추가되는 양은:

```text
현재 오차 × 시간 간격

= 1 × 0.1
= 0.1
```

따라서 새로운 누적값은:

```text
기존 누적값 + 새로 추가되는 양

= 0.4 + 0.1
= 0.5
```

이다.

즉:

```text
A = 0.5
```

가 된다.

---

# 7. 중요한 점: `A`는 튜닝하는 값이 아니다

PID 튜닝에서 사용자가 직접 조절하는 값은:

```text
Kp
Ki
Kd
```

이다.

반면:

```text
A
```

또는 코드의

```python
integral
```

은 프로그램이 실행하면서 자동으로 계산하고 저장하는 값이다.

구조는 다음과 같다.

```text
현재 오차
   ↓
error * dt
   ↓
기존 integral에 더함
   ↓
새로운 integral
   ↓
Ki를 곱함
   ↓
I항
```

---

# 8. `Ki`의 역할

예를 들어 누적값이:

```text
integral = 0.5
```

라면 `Ki`에 따라 I항의 크기가 달라진다.

```text
Ki = 1

I = 1 × 0.5
  = 0.5
```

```text
Ki = 2

I = 2 × 0.5
  = 1.0
```

```text
Ki = 0.5

I = 0.5 × 0.5
  = 0.25
```

따라서:

> `integral`은 지금까지 쌓인 오차이고, `Ki`는 그 누적 오차를 제어 출력에 얼마나 강하게 반영할지를 결정한다.

---

# 9. 물리학적 계산과 컴퓨터 구현의 차이

| 구분 | 수학/물리학 | 컴퓨터 |
|---|---|---|
| 시간 | 연속적 | 일정한 주기의 샘플 |
| 적분 | 시간 전체의 누적 | 매 주기마다 누적 |
| 현재 상태 | 수식으로 표현 | 변수에 저장 |
| 과거 정보 | 수식에 포함 | 변수로 기억 |
| 계산 방식 | 연속적인 계산 | 반복적인 계산 |
| PID 실행 | 수학적 모델 | 측정 → 계산 → 출력 반복 |

중요한 것은 **수학적 PID와 컴퓨터 PID가 서로 다른 원리를 사용하는 것이 아니라는 점**이다.

컴퓨터가 연속적인 수학적 개념을 **실제로 실행할 수 있는 형태로 바꾸어 사용하는 것**이다.

---

# 10. 컴퓨터적인 사고방식으로 PID 보기

PID 코드를 볼 때 수식을 먼저 외우기보다 다음과 같이 생각한다.

```text
① 현재 오차가 얼마인가?

② 이전에 누적된 오차가 얼마인가?

③ 이번 오차를 적분값에 추가한다.

④ 이전 오차와 현재 오차를 비교한다.

⑤ P, I, D를 각각 계산한다.

⑥ P + I + D를 계산한다.

⑦ 출력 범위를 벗어나면 제한한다.

⑧ 현재 오차를 저장한다.

⑨ 다음 주기에 다시 반복한다.
```

결국 PID는 **상태를 기억하면서 계속 업데이트하는 프로그램**이다.

---

# 11. 실제 코드로 연결

가장 기본적인 PID 구조는 다음과 같이 볼 수 있다.

```python
# 현재 오차
error = target - current

# I항: 오차 누적
integral += error * dt

# P항
P = Kp * error

# I항
I = Ki * integral

# D항
D = Kd * (error - previous_error) / dt

# PID 출력
output = P + I + D

# 다음 계산을 위해 현재 오차 저장
previous_error = error
```

이 코드를 보면 PID 공식이 단순히 수학 공식으로 끝나는 것이 아니라:

```text
센서 측정
→ 오차 계산
→ 과거 데이터 확인
→ 현재 데이터 추가
→ P/I/D 계산
→ 모터 출력
→ 상태 저장
→ 반복
```

이라는 **컴퓨터 프로그램의 흐름**으로 바뀐다는 것을 알 수 있다.

---

# 12. 이번 실습에서 이해한 핵심

### 적분

```text
과거부터 현재까지 오차를 누적하는 것
```

### `integral` 또는 `A`

```text
지금까지 누적된 오차를 저장하는 변수
```

### `dt`

```text
이번 측정과 다음 측정 사이의 시간 간격
```

### `Ki`

```text
누적된 오차를 얼마나 강하게 제어에 반영할지 결정하는 값
```

### 컴퓨터에서의 적분

```python
integral += error * dt
```

### PID의 본질

```text
현재를 측정하고
과거를 기억하고
변화를 계산한 다음
다음 움직임을 결정한다.
```

---

## 오늘의 한 줄 정리

> **물리학에서는 PID를 연속적인 수식으로 표현하지만, 컴퓨터에서는 그 수식을 "측정 → 계산 → 변수 업데이트 → 출력 → 반복"이라는 알고리즘으로 바꿔 실행한다. 특히 적분은 `오차 × 시간 간격`을 매 주기마다 누적하는 방식으로 구현된다.**
