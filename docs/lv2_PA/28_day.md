# TIL — 회전행렬 검증과 가우스 소거법

오늘은 회전행렬의 수치 오차를 복구하고 pytest로 검증한 뒤, 가우스 소거법과 rank 판정까지 구현했다.

## 1. 회전행렬과 재직교화

회전행렬은 다음 두 조건을 만족해야 한다.

\[
R^T R = I,\qquad \det(R)=1
\]

부동소수점 연산으로 회전을 20만 번 누적하면 직교성 오차가 생긴다.

- float64 누적 오차: `2.383677964497922e-11`
- float32 누적 오차: `0.0006846852982080445`
- float32는 float64보다 약 `2.87 × 10^10`배 오차가 컸다.

Gram-Schmidt 재직교화 후:

- 직교성 오차: `2.2652158746862216e-16`
- 개선 배율: 약 `105229.62`배
- 원래 행렬과 최대 성분 차이: `5.9037219557467324e-12`
- 행렬식: `1.0000000000000002`
- 따라서 복구 행렬은 회전행렬이다.

## 2. pytest로 회전행렬 검증

`tests/test_rotation.py`에 다음 네 가지 테스트를 작성했다.

1. 각 열이 단위벡터이고 서로 직교하는지

## 3. 가우스 소거법

가우스 소거법은 첨가행렬 `[A|b]`에 행 연산을 적용해 상삼각행렬을 만든 뒤, 후진 대입으로 해를 구한다.

구현 시 중요한 점:

- 부분 피벗팅: 현재 열에서 절댓값이 가장 큰 원소를 피벗으로 선택
- `steps`에 초기 첨가행렬과 소거 과정을 저장
- `verbose=True`일 때 각 단계 출력
- 마지막에는 후진 대입으로 해 벡터 반환

예제의 해는 다음과 같았다.

```text
x = [2, -1, 3]
```

잔차 \(\|Ax-b\|\)는 약 `3.58e-15`로 거의 0이었다.

## 4. rank로 해의 존재성 판정

연립방정식 \(Ax=b\)는 계수행렬과 첨가행렬의 rank를 비교해 판정할 수 있다.

- `rank(A) = rank([A|b]) = 미지수 개수` → 유일해
- `rank(A) = rank([A|b]) < 미지수 개수` → 해가 무한히 많음
- `rank(A) < rank([A|b])` → 해 없음

## 5. det와 condition number

`det(A)`가 작다고 해서 항상 수치적으로 위험한 것은 아니다.

행렬 전체를 작은 상수 \(s\)배 하면:

\[
\det(sA)=s^n\det(A)
\]

이므로 det는 매우 작아질 수 있다. 하지만 condition number는 그대로일 수 있다.

반대로 거의 특이한 행렬은 작은 피벗으로 나누게 되어 반올림 오차가 크게 증폭된다. 따라서 실제 수치 안정성은 det의 절댓값만 보지 않고 condition number도 함께 확인해야 한다.
