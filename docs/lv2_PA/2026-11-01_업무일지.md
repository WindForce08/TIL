## 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 기존 build 폴더로 colcon build 실패 | CMakeCache 가 예전 저장소 경로에서 만들어짐 | 기존 폴더는 그대로 두고 scratchpad 에 `--build-base` · `--install-base` · `--log-base` 로 따로 빌드 |
| mission · perception 빌드 실패 | nav2_msgs · libzbar 미설치 | 설치는 승인 사항이라 그대로 둠. 전체 환경 (Jetson 등) 에서 다시 빌드 필요 |
| 노드 실행 · 통신 시험 못 함 | controller_manager 등 실행 패키지 미설치 | 코드 · 설정의 이름 · 타입 · QoS 를 패키지끼리 맞춰 봄 |
| venv `pip list` 출력이 없음 | 미확인 | `importlib.metadata` 로 버전 확인 |
| 경기장 최단 경로 첫 계산이 틀림 ("막힘" 오판) | 접근점을 한쪽에서 먼저 고름 | 출발점에서 Dijkstra 한 번 + 물체 둘레 점 중 최소 |
