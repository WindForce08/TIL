### Ubuntu 재설치

- Ubuntu를 USB를 이용해 재설치
- Windows가 설치된 디스크와 Windows Bootloader를 건드리지 않는 방향으로 설치
- Ubuntu 환경에서 개발 작업을 다시 구성

### ROS 2 환경

Ubuntu 24.04 환경에서 ROS 2 설치를 진행했습니다.

- ROS 2 APT Repository 구성
- `apt update / upgrade`
- ROS 2 Desktop 설치 시도
- 초기에는 의존성 문제로 설치 실패
  - OpenCV 4.10
  - PCL 1.15
  - PySide6 등
- 이후 ROS 2 환경을 확인하면서 `ROS_DISTRO`, `ros2` 명령 등을 점검

특히 다음과 같은 환경 문제도 확인했습니다.

```bash
echo $ROS_DISTRO
```

결과:

```text
lyrical
```

그리고

```bash
ros2 --version
```

에서는 `--version` 옵션을 지원하지 않아 오류가 발생했습니다.

→ **ROS 2가 정상적으로 설치되어 있는지 단순히 `ros2 --version`으로 판단하면 안 된다는 점을 확인했습니다.**

## 3. Intel RealSense D435 실습

오늘 새 환경에서 **RealSense D435 카메라를 실제로 인식시키고 Python으로 데이터를 받아오는 것까지 성공**했습니다.

### 환경 구성

Python 가상환경:

```text
.venv
```

설치한 주요 패키지:

- NumPy
- OpenCV
- `pyrealsense2`

초기에는 NumPy가 없어 오류가 발생했지만 필요한 패키지를 설치하면서 해결했습니다.

### RealSense 인식

D435가 USB 3.2로 정상 인식되었습니다.

```text
RealSense D435
Serial: 261822079801
USB 3.2
```

그리고 실제 컬러 프레임:

```text
640 × 480 × 3
```

을 정상적으로 받아오는 것까지 확인했습니다.

즉,

```text
USB 인식
  ↓
RealSense SDK
  ↓
pyrealsense2
  ↓
카메라 연결
  ↓
Color Frame 수신
```

까지 검증한 것입니다.

### 오류 수정

RealSense API 사용 중

```python
usb_type_describer
```

라는 오타가 있었고,

```python
usb_type_descriptor
```

로 수정했습니다.

또 기존 `test.py`는 프레임을 제대로 계속 출력하는 구조가 아니어서 `while True`, `cv2.imshow()`, `cv2.waitKey()` 등을 사용하는 스트리밍 구조로 수정하는 방향을 잡았습니다.

## 5. OpenCR 펌웨어

OpenCR 펌웨어를 대상으로

- 빌드
- 컴파일
- 업로드
- CRC 검증
- 실행

과정을 진행했습니다.

업로드 과정에서 정상적으로

```text
CRC OK
[OK] Download
```

를 확인했고, 실제 OpenCR 동작까지 확인했습니다.

OpenCR USB 연결은 다음 장치로 확인했습니다.

```text
/dev/ttyACM0
```

## 7. PID 제어 실습

Dynamixel을 대상으로 PID 제어 실습도 진행했습니다.

기본적으로 다음 세 가지 게인을 조절했습니다.

| 항목 | 의미 |
|---|---|
| Kp | 현재 오차에 얼마나 강하게 반응할지 |
| Ki | 누적된 오차를 얼마나 보정할지 |
| Kd | 오차 변화 속도를 얼마나 억제할지 |

실습에서는 특히 **Kp 변화에 따른 모터 응답 차이**를 확인했습니다.

예를 들어:

```text
Kp = 4
Kp = 2
```

등의 조건을 비교하여 실제 모터의 움직임과 오차를 관찰했습니다.

이 과정에서 단순히 "PID 공식"을 공부한 것이 아니라,

```text
목표 위치
   ↓
현재 위치와의 오차
   ↓
PID 계산
   ↓
모터 제어
   ↓
실제 위치 변화
   ↓
다시 오차 계산
```

이라는 **폐루프 제어(Closed-loop Control)**의 실제 동작을 경험했습니다.
