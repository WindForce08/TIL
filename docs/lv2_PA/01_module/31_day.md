# PID 제어 실습 대화 정리

## 1. PID 실습 코드의 입력 방식

### 사용자 질문

* 업로드한 OpenCR + Dynamixel PID 제어 코드의 사용법 질문
* 입력값이 4가지인지 확인

### 답변 핵심

실제 `s` 실행 명령은 **5개의 입력값**을 받음.

```text
s <Kp> <Ki> <Kd> <speed_deg_s|max> <angle_deg>
```

예시:

```text
s 3 0 0 20 90
```

각 값:

| 값    | 의미        |
| ---- | --------- |
| `3`  | Kp        |
| `0`  | Ki        |
| `0`  | Kd        |
| `20` | 최대 속도 °/s |
| `90` | 목표 각도     |

또한 개별 설정 후 `s`로 실행하는 방식도 지원:

```text
k 3
i 0
d 0
v 20
a 90
s
```

---

## 2. 팔 관절 PID 튜닝 방향

### 사용자 질문

* 팔 관절 테스트 중 오차를 줄이고 최대한 빠르게 안정 범위에 들어가려면 어떤 값을 넣어야 하는지 질문
* PID 제어 실습 목적

### 답변 핵심

처음부터 세 게인을 동시에 조정하지 않고 다음 순서로 튜닝하는 것이 좋음.

```text
Kp → Kd → Ki
```

초기에는:

```text
Ki = 0
```

으로 두고 Kp와 Kd 중심으로 테스트.

추천 실습 예:

```text
s 2 0 0 20 45
s 5 0 0 20 45
s 10 0 0 20 45
s 20 0 0 20 45
```

Kp를 높여가며 진동/오버슈트가 발생하기 시작하는 지점을 관찰.

그 후 Kd 추가:

```text
s 10 0 1 20 45
s 10 0 2 20 45
s 10 0 5 20 45
```

마지막으로 지속적인 위치 오차가 남을 경우 Ki를 조금씩 추가:

```text
s 10 0.1 2 20 45
s 10 0.2 2 20 45
```

### 추가 확인사항

속도 제한도 응답속도에 영향을 줌.

```text
s 10 0 2 20 45
```

에서 최대 속도는 `20°/s`이므로 목표까지 물리적으로 이동하는 시간이 제한됨.

빠른 응답을 실험하려면:

```text
s 5 0 1 60 45
```

처럼 속도 제한을 높여 테스트할 수 있음.

---

# 3. `error_deg`의 의미

### 사용자 질문

* `error_deg` 값이 너무 크다고 질문

### 답변 핵심

코드에서:

```cpp
error_rad = target_rad - position_rad;
```

이므로:

```text
error = 목표 위치 - 현재 위치
```

입니다.

예:

```text
목표 = 45°
현재 = 5°

error = 45 - 5 = 40°
```

따라서 목표에서 멀리 떨어져 있을 때 `error_deg`가 큰 것은 정상.

중요한 것은 **처음 값 자체보다 시간이 지나면서 얼마나 빠르게 감소하는지**임.

정상적인 예:

```text
45
 ↓
40
 ↓
30
 ↓
20
 ↓
10
 ↓
3
 ↓
0
```

반대로:

```text
45
 ↓
44
 ↓
43
 ↓
42
...
```

처럼 천천히 줄어들면 응답이 너무 느린 것.

---

# 4. Kp / Ki / Kd의 의미

## Kp — 비례 제어

핵심:

> **현재 오차가 얼마나 큰지를 보고 즉각적으로 반응**

개념:

```text
P = Kp × error
```

오차가 클수록 강하게 움직이고, 목표에 가까워질수록 출력이 작아짐.

### Kp가 너무 작으면

* 반응이 느림
* 목표까지 오래 걸림
* 오차가 크게 남을 수 있음

### Kp가 너무 크면

* 목표를 지나치는 오버슈트
* 진동 발생 가능

---

## Ki — 적분 제어

핵심:

> **오차가 얼마나 오랫동안 지속됐는지를 누적하여 보정**

예를 들어 목표가 60°인데 실제 위치가 계속 58°에 머물러 `2°`의 오차가 지속되면 Ki가 그 오차를 계속 누적해 보정.

### Ki가 너무 크면

* 적분값이 과도하게 누적
* 오버슈트 증가
* 진동 발생 가능

따라서 PID 튜닝 초반에는:

```text
Ki = 0
```

으로 두는 것이 좋음.

---

## Kd — 미분 제어

현재 코드에서는 일반적인 위치 오차 미분 대신 **측정된 모터 속도**를 이용함.

코드:

```cpp
d_term = -kd * measured_speed_rad_s;
```

핵심:

> **목표에 너무 빠르게 접근할 때 제동하는 역할**

따라서 Kd는 자동차의 브레이크와 비슷하게 이해할 수 있음.

### Kd가 너무 작으면

* 오버슈트가 커질 수 있음
* 목표 주변에서 진동할 수 있음

### Kd가 너무 크면

* 움직임이 둔해질 수 있음
* 목표 접근이 지나치게 억제될 수 있음

---

# 5. 세 PID 값의 직관적 이해

팔 관절을 목표 각도로 이동시키는 상황에서:

```text
Kp = 가속기
Ki = 누적 오차 보정
Kd = 브레이크
```

또는 질문 형태로 기억하면:

```text
Kp → "지금 얼마나 멀리 떨어져 있지?"

Ki → "오차가 계속 남아 있지?"

Kd → "지금 너무 빠르게 접근하고 있지?"
```

---

# 6. 현재 실습에서의 PID 튜닝 순서

```text
① Ki = 0으로 고정
        ↓
② Kp를 증가시키며 응답속도 확인
        ↓
③ 오버슈트/진동 발생 여부 확인
        ↓
④ Kd를 증가시켜 제동
        ↓
⑤ 안정적인 응답 확보
        ↓
⑥ 지속적인 정상상태 오차가 있을 경우 Ki 추가
```

목표는:

```text
빠른 접근
   +
작은 오버슈트
   +
빠른 안정화
   +
최종 위치 오차 최소화
```

입니다.

---

# 결정사항

* `s` 명령은 **5개 입력값**을 사용한다.
* PID 튜닝은 **Kp → Kd → Ki** 순서로 진행한다.
* 초기 실습에서는 **Ki=0**으로 둔다.
* `error_deg`의 절대적인 크기보다 **시간에 따른 감소 형태**를 관찰한다.
* `Kp`는 응답성을 높이고, 너무 높으면 오버슈트/진동을 만든다.
* `Kd`는 빠른 접근을 제동하여 오버슈트와 진동을 줄이는 데 사용한다.
* `Ki`는 지속적으로 남는 정상상태 오차를 제거하는 데 사용한다.
* PID 게인 비교 시 속도 제한을 일정하게 유지하는 것이 좋다.

# 현재 단계의 핵심 개념

```text
목표각도
   ↓
error = 목표 - 현재
   ↓
┌─────────────┐
│     PID     │
│             │
│ Kp → 반응   │
│ Ki → 누적   │
│ Kd → 제동   │
└──────┬──────┘
       ↓
   속도 명령
       ↓
   모터/관절
       ↓
   현재 위치
       ↓
     error
       ↺
```

현재 실습의 다음 단계는 **실제 `error_deg`, `position_deg`, `u_deg_s` 그래프를 보고 Kp/Kd를 어떻게 조절해야 하는지 판단하는 것**입니다.




# 지글러–니콜스(Ziegler–Nichols) 튜닝법 학습 정리

## 1. 학습 주제

* 주제: **지글러–니콜스(Ziegler–Nichols) PID 튜닝법**
* 방식: **폐루프 튜닝법 / Ultimate Gain Method(한계감도법)**
* 핵심 목표:

  * `Ku`(Ultimate Gain, 한계 이득) 찾기
  * `Tu`(Ultimate Period, 한계 주기) 측정
  * 이를 이용해 `Kp`, `Ki`, `Kd` 결정

---

# 2. PID 기본 개념

PID 제어기는 다음과 같이 구성된다.

$$
u(t)=K_p e(t)+K_i\int e(t)dt+K_d\frac{de(t)}{dt}
$$

| 항목    | 의미    | 직관적인 역할        |
| ----- | ----- | -------------- |
| **P** | 비례 제어 | 현재 오차에 반응      |
| **I** | 적분 제어 | 오차를 누적해서 반응    |
| **D** | 미분 제어 | 오차가 변하는 속도에 반응 |

### P 제어 예시

목표 각도가 `90°`이고 현재 각도가 `80°`라면

$$
e=90-80=10^\circ
$$

P 제어에서는

$$
u=K_p e
$$

이므로

$$
u=K_p\times10
$$

이 된다.

---

# 3. 지글러–니콜스 폐루프 튜닝법

핵심 아이디어는 **P 제어만 사용한 상태에서 Kp를 점점 증가시키는 것**이다.

처음에는:

```text
Ki = 0
Kd = 0
```

으로 설정한다.

그다음:

```text
Kp 증가
   ↓
반응성 증가
   ↓
진동 발생
   ↓
Kp를 더 증가
   ↓
감쇠되지 않는 지속적인 진동
```

상태를 찾는다.

---

# 4. Ku — Ultimate Gain

**Ku = Ultimate Gain(한계 이득)**

Kp를 증가시키다가 시스템이 **일정한 크기로 계속 진동하는 상태**가 되었을 때의 Kp이다.

개념적으로:

```text
목표값
────────────────────────

      /\          /\          /\
     /  \        /  \        /  \
────/────\──────/────\──────/────\──
```

이때의 비례 게인을

$$
\boxed{K_u}
$$

라고 한다.

---

# 5. Tu — Ultimate Period

**Tu = Ultimate Period(한계 주기)**

Ku 상태에서 발생하는 지속적인 진동의 **한 주기 시간**이다.

```text
      /\                  /\
     /  \                /  \
────/────\──────────────/────\────
    ↑                    ↑
    │<------- Tu -------->│
```

첫 번째 peak에서 다음 peak까지 걸리는 시간을 측정한다.

예:

```text
Ku = 50
Tu = 0.8초
```

---

# 6. Ziegler–Nichols 튜닝 공식

## P 제어

$$
\boxed{K_p=0.5K_u}
$$

---

## PI 제어

$$
\boxed{K_p=0.45K_u}
$$

$$
\boxed{T_i=\frac{T_u}{1.2}}
$$

---

## PID 제어

$$
\boxed{K_p=0.6K_u}
$$

$$
\boxed{T_i=\frac{T_u}{2}}
$$

$$
\boxed{T_d=\frac{T_u}{8}}
$$

---

# 7. 예제

실험 결과가 다음과 같다고 가정한다.

```text
Ku = 40
Tu = 0.6 sec
```

PID 튜닝을 하면:

### Kp

$$
K_p=0.6\times40
$$

$$
\boxed{K_p=24}
$$

### Ti

$$
T_i=\frac{0.6}{2}
$$

$$
\boxed{T_i=0.3}
$$

### Td

$$
T_d=\frac{0.6}{8}
$$

$$
\boxed{T_d=0.075}
$$

따라서:

```text
Kp = 24
Ti = 0.3
Td = 0.075
```

---

# 8. 중요한 주의점 — Ki, Kd를 직접 구한 것이 아니다

PID 코드가 `Kp`, `Ki`, `Kd`를 직접 입력받는 구조라면 주의해야 한다.

지글러–니콜스 공식에서 나오는 것은 보통:

```text
Kp
Ti
Td
```

이다.

일반적인 PID 표현에서는:

$$
K_i=\frac{K_p}{T_i}
$$

$$
K_d=K_pT_d
$$

로 변환할 수 있다.

위 예제라면:

$$
K_i=\frac{24}{0.3}=80
$$

$$
K_d=24\times0.075=1.8
$$

따라서 구현 방식에 따라:

```text
Kp = 24
Ki = 80
Kd = 1.8
```

처럼 사용하게 될 수 있다.

**단, 사용하는 PID 코드의 정의를 반드시 확인해야 한다.**

# 9. 로봇 관절에 적용할 때

희우님이 사용하는 로봇 관절/모터 제어에서는 특히 주의해야 한다.

지글러–니콜스는 의도적으로 시스템을 **지속적인 진동 상태까지 접근**시킨다.

```text
정상
 ↓
Kp 증가
 ↓
진동 발생
 ↓
Kp 증가
 ↓
지속적인 진동
 ↓
Ku 측정
 ↓
Tu 측정
 ↓
PID 계산
```

따라서 실제 로봇에서는:

* 관절이 크게 흔들릴 수 있음
* 모터에 큰 부하가 걸릴 수 있음
* 감속기에 충격이 발생할 수 있음
* Kp를 너무 빠르게 증가시키면 위험할 수 있음

때문에 **작은 값부터 단계적으로 증가시키는 것**이 중요하다.

---

# 10. 이번 학습의 핵심 구조

```text
Ziegler–Nichols 폐루프 튜닝

① Ki = 0
   Kd = 0

        ↓

② Kp를 조금씩 증가

        ↓

③ 지속적인 진동 발생

        ↓

④ 그때의 Kp = Ku

        ↓

⑤ 진동 주기 측정 = Tu

        ↓

⑥ Ziegler–Nichols 공식 적용

        ↓

⑦ Kp / Ti / Td 계산

        ↓

⑧ 코드의 PID 형식에 맞게
   Ki / Kd로 변환

        ↓

⑨ 실제 로봇에서 미세 조정
```

# 11. 이번 대화에서 결정된 핵심 개념

| 개념              | 의미                                 |
| --------------- | ---------------------------------- |
| `Kp`            | 비례 게인                              |
| `Ku`            | 지속적인 진동이 발생하는 한계 게인                |
| `Tu`            | 그 진동의 한 주기                         |
| `Ti`            | 적분 시간                              |
| `Td`            | 미분 시간                              |
| Ziegler–Nichols | `Ku`, `Tu`를 이용해 PID 초기값을 정하는 튜닝 방법 |

### 가장 중요한 한 문장

> **Kp만 올려서 지속적인 진동이 발생하는 지점의 `Kp = Ku`, 그 진동의 주기가 `Tu`이고, 이 두 값을 Ziegler–Nichols 공식에 넣어 PID 초기값을 결정한다.**
