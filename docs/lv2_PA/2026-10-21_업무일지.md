## 1. 요약
- RM-X52 집게 위에 USB 카메라(Arducam UC-684_B0201) 브래킷을 만들고 6WD 차체에 병합함.
- 집게에 손목 롤 관절(XM430-W350-T + RW-01)을 넣고, 롤 모터 커넥터 창을 냄.
- 받은 바퀴·OpenCR STL을 분석해 차체 모델의 제자리에 넣음 (바퀴 36 g).
- 차체 모델에서 URDF를 만들고, 이미 설치된 Isaac Sim 6.1 / Isaac Lab 3.0에서 창 없이 USD 변환, 물리 확인, 주행 학습까지 돌림.

## 2. TeamRobot 6WD

### 2.1 집게 카메라 브래킷
- 카메라 용도: 퍽 색·거리(화면 속 크기), 신호등, 마커 인식.
- 렌즈를 10 mm 올리고 광축을 15° 아래로 기울임.
- 고정: 집게 윗면 원래 나사 2개 자리와 옆벽 빈 구멍 2개에 M2.5x8 4개. 카메라는 M2.5x14 + 너트 4개.
- 출력 37분, 20 g. 나사가 들어가는 것은 실물로 확인함.

### 2.2 손목 롤 관절
- J4 브래킷 → 롤 모터 혼 → RW-01이 모터 몸통을 감쌈 → 집게.
- 먼저 시뮬레이션 그림으로 구조를 확인하고, 커넥터 창을 내서 반영함.
- 나사: M2x3 8개, M2.5x5 8개, M2.5x16 4개.
- 롤은 360° 내내 닿는 곳 없음. 요 회전 범위 ±142° → ±137°, J4 부하 +84%.
- RW-01 출력 30분, 14 g.

### 2.3 바퀴·OpenCR 실제 형상
- 바퀴: Ø66 x 18.2, 36 g, M2x3 4개씩. 겉모양은 실제 메쉬, 검사·STEP·무게는 단순 솔리드.
- OpenCR: 실제 STL을 기존 자리에 넣고, 검사 형상을 실제 보드를 덮도록 넓힘.
- 검사:
  - 부품 231개, 간섭 0, 나사 물림 132건 일치, 독립 검사 53/53.
  - 무게 4362 g. 팔 뻗고 500 g이면 앞쪽 전복각 5.0°.
- 확인할 점:
  - 바퀴가 혼 면에서 0.2 mm 뜸.
  - 모터 아래 플러그와 지면 사이 3.75 mm.

### 2.4 URDF와 Isaac Sim / Isaac Lab
- URDF:
  - 몸체 14개, 관절 13개, 질량 4.362 kg.
  - 충돌은 상자·원통만 씀. `check_urdf` 통과.
- 이미 설치된 `~/pa-course/IsaacLab-6.1`을 그대로 씀 (새로 설치 안 함, 창 없이).
- 물리 확인 결과:
  - 차체 높이 URDF와 같음.
  - 직진 미끄럼 1 %.
  - 제자리 회전 18.5 °/s.
  - 팔·손가락이 목표 위치에 도달.
- 주행 과제 PPO 학습: 64 환경, 300회, 136초. 보상 −8 → 37, GPU 3.4 / 8 GB.

### 2.5 생긴 문제와 해결
- FreeCAD 강제 종료(137) → 실행 스크립트가 최대 4번 다시 실행.
- 같은 형상을 공유한 바퀴가 STEP에서 빠짐 → 바퀴마다 형상 복사.
- Isaac Lab 3.0에 `--headless` 옵션이 없음 → `HEADLESS=1`로 실행.
