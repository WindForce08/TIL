### 2.2 롤백 파일 백업과 GPU 확인
- `~/nvidia-rollback-595.91.07/`에 현재 드라이버 `.deb` 17개(309 MB)를 복사하고 `SHA256SUMS`를 남김. 저장소에서 이미 내려간 버전이라 이 사본이 유일한 되돌리기 수단임.
- GPU 상태: 화면 렌더링은 NVIDIA RTX 5060이 담당함 (PRIME 성능 모드). Intel 내장 그래픽은 노트북 패널로 화면을 넘겨주는 역할만 함.

### 2.3 Git 백업 구조 점검 (PA-Backup)
- 원인: `~/GIT` 아래 9개 폴더가 각자 독립 저장소라서, 상위에서 push해도 파일이 아니라 커밋 번호(gitlink)만 기록됨. PA-Backup을 받으면 그 폴더들은 빈 폴더로 나옴.
- `.git`이 있는 폴더 15개를 찾아 원격·브랜치를 정리하고, 어디에도 백업되지 않은 변경 목록을 정리함.
- 방법 비교: 미러 폴더 방식(rsync, 권장) / 하위 `.git` 삭제 / 정식 서브모듈 / 혼합. 팀 저장소(SpartaPA)와 다른 사람 저장소는 연결을 유지해야 하며, PA-Backup은 비공개여야 함을 확인함.
- 권한 000으로 막힌 폴더(`docs/Kit/shared/screenshots`)가 백업에서 빠지는 것도 확인함.

### 2.4 TeamRobot 6WD 섀시 모델 (FreeCAD)
- 작업 지시서대로 새 모델 작성: 하판 250 x 270 x 9, 모터(XM430) 6개, OpenCR 2개, TFmini Plus, Jetson Orin Nano, 배터리 2개.
  - 1차 모델: 부품 134개 간섭 0, STEP 재가져오기 검사 19/19 통과.
- 지시 반영 1: 모터 브래킷을 없애고 **하판에 직접 장착**. 모터당 M2.5x8 렌치볼트 4개 (하판 윗면 카운터보어).
- 지시 반영 2: 좌우에 **높이 80, 두께 7 벽** 추가.
  - 벽을 하판 가장자리에 두면 모터 나사 카운터보어와 0.25 mm밖에 안 떨어져서, 나사 줄 안쪽(|X| 88 ~ 95)에 배치함.
  - 나사 축 ~ 벽 면 최소 8.0 mm, 나사 위 공구 공간 모두 확보.
  - 검사: 간섭 0, 독립 검사 22/22 통과.
- 나사 부품 리스트 작성 (체결 부품 64개, 탭 위치, 인서트 대안).
- 바탕화면에 다음 작업용 정리 문서 작성.

## 3. 발견 사항
- 받아 둔 모터 STEP은 XW430이라 측면 탭 위치가 XM430과 다름 → 하판 구멍은 **XM430 공식 도면값**으로 뚫음. 실물 확인 전에는 가공하지 말 것.
- 지시서의 PH M3x8로는 9 mm 하판을 관통할 수 없음 → 스페이서를 하판에 고정하고 보드를 스페이서에 고정하는 구조로 바꿈.
- 눕힌 모터의 위쪽 커넥터는 하판에 가려 쓸 수 없음 → 모터 6개 배선 계획 필요.
